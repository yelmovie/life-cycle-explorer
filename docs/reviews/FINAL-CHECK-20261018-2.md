## 배포 차단 문제와 조건

교육·저장·빌드에서 확인된 FAIL은 없다. 전자칠판 글자 FAIL은 이번 가로 태블릿 범위와 다른 매체의 제약으로 한정해 조건부 판정한다. 전자칠판 전용 사용에는 글자 확대와 교실 뒤쪽 실측이 필요하다.

공개 배포 전 소유자가 제공 이미지의 이용 조건을 확인하고, 교사가 실제 태블릿/학교망에서 학생 시범 사용·이해도·난이도·터치와 시간 조작을 점검해야 한다. 배포 담당자는 실제 배포 URL에서 시작→저장→새로고침을 확인해야 한다. 이번 요청의 Git 커밋과 서비스 공개 배포는 별개다.

## 개선 우선순위 — 최저 3개

1. 전자칠판 7→11: 보조 글자와 Canvas 글자의 확대 모드·자동 스케일, 교실 뒤쪽 가독성 실측. 태블릿 공간을 줄일 위험이 있어 별도 모드가 적합하다.
2. 코드/유지보수 8→11: 기존 압축 행을 기능별로 정리하고 나머지 학습 콘텐츠도 자료로 분리. 현재 저장/82개 회귀/브라우저 흐름을 유지하며 검증해야 한다.
3. 저작권·배포 8→11: 제공 자료의 공개 조건 확정, 실제 배포 URL·학교망 검증. 코드만으로 확인할 수 없다.

새 지도와 연결 길·위치 저장, 지훈 동작·도구, 다섯 의뢰, 원인별 조치와 시간 결과, 실물 기록 연결, 이전 저장 보존, 모달 닫기 이동 취소 문제, 접힌 대체 조작과 실험 선택기를 수정했다.
