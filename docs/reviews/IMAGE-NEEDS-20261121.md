새 그림이 있어야 풀리는 자리만 적었다. 그림은 만들지 않았다. 근거는 [권리 장부](../RIGHTS-LEDGER-20261121.md), [100점 할 일](SCORE-100-TODO-20261120.md), 배포 그림의 픽셀 크기(`sips -g pixelWidth -g pixelHeight`로 잼), 그리고 지금 작업 트리의 코드(햇살 온실 돌봄 조작은 아직 커밋 전)다.

| 갈래 | 장수 |
|---|---:|
| (가) 권리 장부에서 출처 미확인인 그림 | 0 (3-2a에서 1 → 0) |
| (나) 화풍·해상도가 튀거나 임시로 넣은 그림 | 1 |
| (다) 할 일 목록의 게임성·화면 보강에 필요한 소품·배경 | 1 |

배경 그림은 `src/field-scenes.js`의 `backdrop()`이 화면을 꽉 덮도록(cover) 키운다. 캔버스는 기기 화소 배율 없이 CSS 크기로 그려진다(`P.Scale.RESIZE`). 그래서 배경의 화면 확대 배율은 `max(화면 너비 / 그림 너비, 화면 높이 / 그림 높이)`다.

| 배경 | 그림 크기 | 1280×800 태블릿 | 1920×1080 전자칠판 |
|---|---|---:|---:|
| `field/observation-clearing.webp` (나비의 숲) | 1586×992 | 0.81배 | 1.21배 |
| `game/seed-lab-greenhouse-v2.jpg` (씨앗 연구소) | 1920×819 | 0.98배 | 1.32배 |
| `game/bg4.webp` (햇살 온실) | 1280×720 | 1.11배 | 1.50배 |
| `field/garden-seasons-v1.webp` (사계절 정원) | 1280×720 | 1.11배 | 1.50배 |
| `game/tower-room-*.webp`, `tower-evidence-board.webp` (시계탑) | 1600×1000 | 0.80배 | 1.20배 |

나머지 소품·캐릭터·카드는 원본보다 작게 그려진다(예: 성취 카드 썸네일 96×144가 26×38 칸, 시계탑 문장 256px가 37~54 단위, 분류 카드 400px가 172 단위 간격). 대화 초상은 512px 칸을 1000×500으로 맞춘 것이라 거의 그대로다.

- `game/bg4.webp`(햇살 온실 배경)도 전자칠판에서 1.5배 확대되지만, 원본 `assets/optimized/scene-05.webp`가 1672×941이라 다시 내보내면 1.15배로 줄어든다. 새 그림은 필요 없다. 다만 장부 L04가 근거 약함이라, 원 제공자 자료가 끝내 없으면 그때 (가)로 옮겨 새로 그릴지 정한다.
