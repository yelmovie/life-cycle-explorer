## 반영
- 개념 영상 잠금 문구: 미션 1·3은 '을', 2·4·5는 '를'.
- 한해를 → 한 해를, 새 싹 → 새싹, 시계 바늘 → 시곗바늘, 다시하기 → 다시 하기, 이어갈 → 이어 갈.
- 연구 노트 / 생명 관찰 노트로 통일. 화면, 생성 원본 JSON, 인쇄 제목까지 반영.
- 로컬 나눔스퀘어네오: DOM, Phaser 캔버스, 연구 노트, 내보내기 PNG, 기록증에 적용.
- 공식 WOFF·OFL 라이선스 포함. 빌드의 WOFF 지원 추가.
- 기존 로컬 서버의 concept-focus.js/css 누락 및 WOFF MIME 보완. 모듈 누락은 로컬 첫 화면을 막고 있었음.
