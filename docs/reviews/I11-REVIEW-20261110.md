## 반영
- 개념 영상 잠금 문구: 미션 1·3은 '을', 2·4·5는 '를'.
- 한해를 → 한 해를, 새 싹 → 새싹, 시계 바늘 → 시곗바늘, 다시하기 → 다시 하기, 이어갈 → 이어 갈.
- 연구 노트 / 생명 관찰 노트로 통일. 화면, 생성 원본 JSON, 인쇄 제목까지 반영.
- 로컬 나눔스퀘어네오: DOM, Phaser 캔버스, 연구 노트, 내보내기 PNG, 기록증에 적용.
- 공식 WOFF·OFL 라이선스 포함. 빌드의 WOFF 지원 추가.
- 기존 로컬 서버의 concept-focus.js/css 누락 및 WOFF MIME 보완. 모듈 누락은 로컬 첫 화면을 막고 있었음.

## 검증
- npm run check: 활성 런타임/빌드 45개 파일 통과.
- npm test: 184개 통과(기존 181개, I11 회귀 3개).
- 기존 완료 조건, 오답 재시도, 기록 저장/복원, 교사 미리보기 분리, 과학 모형 검증 유지.
- Chrome: 1024×768에서 잠금 문구 5종, 설정, 교사 시연, 연구 노트 입력창 확인. 1920×1080 연구 노트 확인. 가로 넘침 없음.
- 인트로·엔딩 자막은 field-cinema.js의 DOM 문구라 MP4 재렌더 불필요.
- 학생 전체 완주 및 실제 기기 터치 검증은 이번 문구·폰트 수정에서 새로 수행하지 않음.

## 추가 수정 (같은 날, 커밋 622373c 이후)
- 위 커밋의 가변 글꼴(NanumSquareNeo-Variable.woff)은 Chrome에서 열리지 않아 화면이 맑은 고딕으로 대체되고 있었음. 네이버 공식 굵기별 WOFF 3개(보통·굵게·아주 굵게)로 교체하고 Chrome에서 로드를 확인함. 가변 파일은 `assets/fonts/source/`로 옮겨 빌드에서 제외.

- 같은 유형 맞춤법: 이어가자 → 이어 가자, 이어가기 → 이어 가기, 직접 해보기 → 직접 해 보기. 인쇄 파일명 `나의-생명-관찰-노트.png`.

- 검증: npm test 184개 통과, npm run check 통과, npm run build 완료. 1280×800 외 화면 크기와 실제 기기는 다시 확인하지 않음.
