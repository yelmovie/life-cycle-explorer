## 수치

같은 Windows Chrome·1280×800·격리 컨텍스트에서 실행했다. 초기 로딩 측정은 서비스워커를 차단하고, 최초 활동 화면 준비 시점까지 집계했다. 배경 오프라인 준비의 통신량을 초기 로딩 수치에 숨겨 합산하지 않았다.

| 측정 | 수정 전 | 수정 후 |
|---|---:|---:|
| 로컬 새 컨텍스트 준비 | 2,013ms | 1,607ms |
| 10Mbps·왕복 지연 모사 60ms 준비 | 4,375ms | 3,124ms |
| 위 조건 첫 글자 표시 | 1,880ms | 320ms |
| 위 조건 초기 전송량 | 4,404,491B | 2,657,843B |
| 위 조건 초기 HTTP 요청 수 | 50 | 51 |
| 오프라인 전체 자료 | 없음 | 152개 배포 파일 + 준비 표식 1개 |

배포 자료 총량은 17.58 MiB(런타임 48파일·에셋 104개)다. 첫 준비는 기기마다 이 자료를 받아야 한다. 실제 학교 30대 동시 부하·프록시·Wi-Fi 로밍·실기기 저장소 회수는 미검증이다.
