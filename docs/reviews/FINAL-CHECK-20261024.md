## 계획과 적용

사전 범위·회귀 위험·항목별 목표는 [개선 계획](FINAL-CHECK-PLAN-20261024.md)에 있다. 적용한 주요 변경은 다음과 같다.

1. **관찰·시연 복구:** 나비의 숲에서 생물 위로 움직이는 실제 확대 렌즈를 복원했다. 교사 도구는 전체 입구와 30개 내부 활동을 시연용 상태로 열며 학생 원본에 쓰지 않는다.
2. **화면·설정:** 작은 글자와 조작 영역, 낮은 화면·큰 지도 겹침, 초기 세로 안내를 고쳤다. 선택적 개념 영상은 완료한 구역만 모아 볼 수 있고 닫으면 목록으로 돌아온다.
3. **학습 동기·결말:** 첫 보상을 미리 보여 주고 개인의 능력 진술·생활 관찰 계획을 결말에 연결했다. 기존 이야기 입력에 “나는 이제 …을 증거로 설명할 수 있어” 안내를 더했으며 예전 학생 문장은 바꾸지 않았다. 구역마다 새로 할 학습 행동을 안내한다.
4. **기술:** 즉시 로더·재시도, 초기 전송량 감소, 문장 데이터 분리, 배포본의 검증된 버전 캐시를 추가했다. 새 버전이 열린 탐험 창을 강제로 바꾸지 않는다.
5. **영상 제작 자료:** 정적이던 6컷을 마을 전경→골목 이동→연구소, 연구소→다리→마을 밖 계곡의 여정으로 다시 만들었다. 실제 새 이미지 6장·움직임 프롬프트 6개·SRT 2개를 정리했다. 인트로·아웃트로 완성 영상 자체를 생성한 것은 아니다.

첫 3분 화면으로 설명할 수 있는 목적은 “내가 관찰하고 실험한 증거로 다섯 장소를 이어서 멈춘 숲의 시간을 되살린다”이다. `.tmp/final-opening/result.json`에 180초의 화면 기록이 있고, 추가한 보상 예고는 최종 dist의 `.tmp/final-release/result.json`에서 다시 확인했다.

가장 약한 구역은 생명 시계탑이다. `.tmp/final-story-review/result.json`의 180초 플레이에서 다른 사진 선택→제목·자기 설명→사진 설명→친구 요청의 증거 연결로 전환했다. 그림을 걷어내도 증거를 고르고 설명을 검토하는 판단은 남는다. 다만 고정 사례를 한 번 해결한 뒤 다시 생기는 판단의 폭은 씨앗 실험보다 좁다. 새 이야기 제작 이유를 추가했지만 이를 실제 아이의 재방문으로 대신 설명하지 않는다.

## 아이스크림 설정 확인

- 배경 음악·효과음·음량, 도입 다시 보기, 완료 후 엔딩·기록증, 완료한 구역의 선택적 개념 영상 목록을 확인했다.
- 앱 정보→학생 가이드→교사 가이드(성취기준·교사용 도구)→저작권과 출처, 접힌 상세 영역과 초기화 확인을 유지했다.
- 교사 시연은 보안 인증이 아니라 미리보기라는 문구, 현재 브라우저 자동 저장·서버 전송 없음, JSON 보관과 실제 불러오기 기능의 차이를 유지했다.
- 사용자가 삭제한 성취기준 안내문을 다시 넣지 않았다. 저작권 3갈래와 출처의 비클릭 표시를 유지했다.
- 두 Suno 곡의 유료 생성 여부는 2026-10-24 사용자 답변에 근거한다. 확인 범위를 `assets/CREDITS.md`에 명시했다.

## 11점까지 남은 조건

- **8 유지보수성:** 문서를 처음 읽는 개발자가 시험 복사본에 새 구역을 추가하는 검증이 필요하다. 문서와 등록 지점은 정리했지만 검증 없이 11점을 주지 않았다.
- **17 로딩:** 같은 10Mbps/60ms 조건에서 3초 미만을 재현해야 한다. 현재 3.124초다. 이 결과를 3초 이내로 반올림하지 않는다.
- **19 학교 환경:** 담당 교사가 실제 수업 기기·동시 접속 환경에서 배포 전에 확인해야 한다. 준비 전 첫 방문은 인터넷이 필요하다.
- **23 재플레이:** 실제 학생이 새 학습 목표 때문에 다시 여는지 첫 파일럿 수업 뒤 확인해야 한다. 타이머나 점수 반복을 추가해 흥미로 간주하지 않았다.
