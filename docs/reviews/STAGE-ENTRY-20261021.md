# 스테이지 입장 후속 수정

사용자가 입장되지 않는다고 보고한 뒤 내장 브라우저의 실제 버튼·화면으로 재현했다. 앞선 서버 응답 확인과 모델 검사만으로 사용자 화면의 정상 실행을 보장한 것은 부족했다.

## 재현한 문제

첫 구역은 정상 입장했다. 그러나 아직 열리지 않은 구역도 일반 입장 버튼처럼 보였고, 그곳까지 걸어간 뒤 작은 도움말 `!`만 생겼다. 잠긴 이유가 바로 보이지 않아 아무 일도 일어나지 않은 것처럼 보였다. 이동 중에는 표시가 없고, 새 목적지 요청은 무시하는 구조였다. 모든 UI 동작이 소리 준비 Promise를 기다리는 구조도 있었다.

## 수정

- 잠긴 구역은 자물쇠·점선으로 구분하며 누르는 즉시 선행 탐사와 바로 갈 수 있는 버튼을 표시한다. 원래 순서 해금과 증거 조건은 유지한다.
- 이동 중 목적지와 진행 상태를 표시하고, 목적지를 바꾸면 마지막 요청을 따른다. 취소한 이동의 이전 콜백은 위치·저장·입장을 변경하지 못한다.
- 안내나 설정을 열면 지도 이동을 멈춰 창 뒤에서 다른 구역에 입장하지 않는다.
- 버튼 동작은 소리 준비 완료를 기다리지 않는다.
- 앞선 Canvas 렌더러 변경 상태로 실제 내장 브라우저에서 다시 검증했다.

## 검증 범위

내장 브라우저 `http://127.0.0.1:4204/`에서 직접 확인:

| 경로 | 결과 |
|---|---|
| 시작 → 지도 → 나비의 숲 | 실제 구역과 관찰 도구 표시 |
| 잠긴 씨앗 연구소 선택 | 선행 탐사 안내가 즉시 표시됨 |
| 안내의 첫 구역 이동 버튼 | 이동 중 표시 후 실제 나비의 숲 입장 |
| 교사 미리보기에서 씨앗 연구소·햇살 온실·사계절 정원·생명 시계탑 | 각 구역의 질문과 도구·활동 화면에 실제 입장 |
| 나비의 숲 돋보기 드래그 | `알의 특징을 발견했어.` 피드백 확인 |
| 시계탑으로 이동 시작 직후 온실 선택 | 최종 선택한 온실에 입장 |
| 이동 중 설정 열기 → 닫기 | 지도에 남고 입장 버튼이 정상 복구됨 |
| 최종 첫 구역 재입장 | 화면 확인 후 탭을 사용자용 결과로 유지 |

교사 미리보기는 학생 상태의 임시 복사본이다. 완료나 증거를 미리 채우지 않았다. 새로고침하면 원래 학생 진행으로 돌아간다. 이번 확인은 입장·지도 이동·첫 관찰 조작에 대한 확인이며 다섯 활동 전체를 다시 완주한 검증으로 기록하지 않는다.
