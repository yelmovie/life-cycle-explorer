## 3D를 넣을 자리

[3D 모델 제작 목록](../3d/3D-MODEL-BRIEF.md)에 14개 모델과 메시 프롬프트를 정리했다.

1. **나비의 숲 표본 돌려 보기** — 확대창에서 알·애벌레·번데기·어른벌레를 손가락으로 돌림. 다리 6개·몸마디를 각도로 찾는 활동이라 교육적 이유가 가장 크다.
2. **보상 획득 연출** — 시간 손잡이·관찰 센서·계절 나침반·이야기 카메라가 돌며 내려옴.
3. **생명 시계탑 엔딩** — 시계 몸체에 금빛 고리·잎 핵이 끼워지고 다시 도는 5초.
4. (선택) 첫 화면 도토 동작, 씨앗 연구소 강낭콩 싹.

3D는 확대창·보상창·엔딩 안에서만 지연 로드하고, 못 여는 기기·동작 줄이기에서는 지금 2D 그림을 그대로 쓴다.
