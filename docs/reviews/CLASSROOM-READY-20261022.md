# 교실 네트워크 내성 — 생명 시계 연구실 0.7.0

2026-10-22. HANDOFF.md의 남은 교실 환경 확인 중 로컬에서 가능한 부분을 점검했다. 게임 코드·학습 판정·저장 키·배포 설정은 변경하지 않았다.

## 확인 환경과 범위

- 기존 dist 미리보기 `http://127.0.0.1:4207`, Chrome headless, 1280×800, 격리된 새 브라우저 저장소.
- dist는 128파일, 11,022,132바이트(10.51MiB). 빌드에 포함된 프로젝트 JS·CSS·HTML과 현재 소스의 SHA-256이 모두 같았다.
- Chrome DevTools Protocol의 HTTP 요청과 `Network.loadingFinished.encodedDataLength`로 전송량을 측정했다. HTTP 헤더도 포함하며 실제 학교망 속도·AP 성능 측정은 아니다.
- 나비 탐사에 온라인으로 입장한 뒤 Playwright `context.setOffline(true)`로 연결을 끊었다. 관찰·그림·글·필름·다음 세대·완료·영상 대체·씨앗 연구소 이동·새로고침·재접속을 확인했다.
- 이전 101개 단위 검사와 화면·미디어 검사는 인계된 결과를 유지했다. 이번에는 네트워크·오프라인 시나리오를 추가 확인했다.

## 실제 기기에서 남은 확인

현재 개발 서버는 `server.mjs:53`에서 `127.0.0.1`에만 바인딩한다. 다른 태블릿에서 이 PC의 localhost 주소를 열 수는 없다. 실제 기기 테스트에는 접근 가능한 고정 테스트 주소를 별도로 준비해야 한다. 이번 작업에서 공개 배포나 서버 공개 설정은 바꾸지 않았다.

| 확인 | 절차와 통과 기준 | 판정 |
|---|---|---|
| 태블릿·전자칠판 터치 | 실제 기기 가로 화면에서 돋보기 끌기, 씨앗 놓기, 시간 조절, 전후 밀기 비교, 이야기 순서 편집. 두 번 처리·스크롤 충돌·화면 잘림이 없는지 확인 | NOT TESTED |
| 실제 스피커·브라우저 정책 | 첫 터치 후 효과음, BGM 켜기·음량·끄기, 영상 동안 BGM 정지, 닫은 뒤 복귀, 다른 탭/복귀를 확인 | NOT TESTED |

학교망 시험에서는 30명이 동시에 처음 열 때 마지막 기기의 시작 가능 시각과 리소스 실패를 기록하고, 활동 중 연결을 끊었다가 복구해 본다. 같은 고정 주소·브라우저를 사용하고 학생이 바뀌기 전에는 PNG·진행 JSON을 보관한 뒤 초기화한다. 현재 오프라인 제약이 있으므로 실제 수업 전에 새로고침·다음 구역 이동의 결과를 교사가 확인해야 한다.
