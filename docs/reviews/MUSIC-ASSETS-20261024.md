## 실제 음악 재생 확인

- `127.0.0.1:4186`에서 메인 곡의 재생 상태와 67.88초 길이, `loop=true`, 디코딩 오류 없음을 확인했다. 검증 후 원래 배경 음악 끄기·효과음 켜기·음량 20% 설정으로 복원했다.
- 이전 직접 완주로 만든 `127.0.0.1:4208`의 별도 기록에서 엔딩을 열었다. 파이널 곡 172.8초, `loop=false`, 실제 재생 상태를 확인했다. 엔딩에서 기록증으로 바꾼 뒤에도 플레이어 1개가 41.584초 지점을 이어 재생했다.
- 엔딩을 닫으면 메인 곡으로 돌아왔다. 개념 영상 중에는 음악이 36.138667초에서 정지했고, 종료 후 36.298667초로 이어 재생됐다. 콘솔 오류·경고 0.
- 최종 구역의 개념 영상 → ‘탐험 마무리’ → 엔딩 경로도 직접 확인했다. 플레이어 1개가 파이널 곡을 35.621333초까지 재생했고, 반복 꺼짐·오류 없음 상태였다. [최종 전환 상태](music-20261024/final-video-to-ending.json)를 보관했다.
- 두 MP3를 FFmpeg로 전체 디코딩해 오류 없음을 확인했다. 이동에 따른 재인코딩이나 음질 변경은 하지 않았다.
- 숨겨진 탭의 정지·재개, 엔딩 끝난 뒤 재시작 방지, 음원 오류 대체, 음량·효과음 독립 제어는 모의 AudioContext/Audio를 사용하는 회귀 검사로 확인했다.
