# 초기 진입 화면 디자인 개선

- 기존 문장형 제목을 ‘생명 시계 연구실’ 두 줄 이미지 로고로 교체했다. 크림·금빛 입체 글자, 짙은 숲색 테두리, 잎과 작은 시계 장식으로 기존 그림의 색과 재질을 따른다.
- ‘작은 씨앗이 숲을 깨울 수 있을까?’를 중심 문구로 두고, 금빛 시작 버튼과 차분한 이어하기 버튼의 위계를 정했다. 지도 명암을 조절하고 지훈·잎새·도토를 함께 배치했다.
- 변경 범위는 제목 화면의 마크업·CSS와 제목 상태의 지도 명암이다. 진행 판정·저장 키·문제·보상은 변경하지 않았다.

## 검증

내장 브라우저의 실제 화면을 기본 크기, 1280×800, 1024×768, 906×600, 375×812에서 확인했다. 로고 표기·투명 가장자리·본문·시작 버튼의 잘림을 확인하고, 제목 화면에서 불필요하게 겹치던 가로 회전 안내를 숨겼다.

‘탐험 시작’의 도입 이야기 열기와 ‘이어서 탐험’의 기존 지도 복귀를 직접 확인했다. 이후 처음 화면으로 돌아왔고 브라우저 크기 지정도 해제했다. 정상 콘솔 오류·경고 0. `npm test` 109/109, `npm run check` 27파일 통과.

`npm run build` 통과: 31개 런타임 파일, 에셋 98개, 10.71 MiB. 원본 PNG는 배포에서 제외했다. [최종 실제 화면](title-screen-20261024/main.png)을 보관했다.

[메인·엔딩 음악 프롬프트](../SUNO-THEMES.md)는 따로 보관했다. 음악 파일은 아직 받지 않았으며 이번 변경에 새 음악을 연결하지 않았다.
