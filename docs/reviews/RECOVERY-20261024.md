# 중단 작업 복구 · 2026-10-24

## 적용 내용

- 이전 채팅의 요청과 실제 저장 파일을 대조했다. 이미 만든 이미지 6장은 재생성하지 않고 복구해 기존 영상 제작 캔버스에 이미지·프롬프트·자막·음악 편집안을 완성했다. 인트로24초/파이널30초는 제작안이며 실제 새 동영상 생성은 요청 범위가 아니다.
- 씨앗 실험은 같은 재료 → B 조건 하나 변경 → 예상 → 시작 → 시간별 사진 순서로 안내한다. 온실은 두 센서 → 흙/잎 직접 표시 → 전 사진 → 돌봄 → 뒤 사진으로 연결했다.
- 관찰 노트의 실제 도구 그림·손글씨·타이핑, 촬영 사진 팝업, 같은 품종의 개 3단계, 회전하는 생명 시계, 완료 건물의 점등, 코르크판 기록을 통합했다. 긴 글은 입력창에서 보존하며 판 위 미리보기만 생략 표시한다.
- 추가 발견 미션은 구역마다 2개씩 총10개다. 메모와 생물 연결, 공정한 비교 수리, 관찰 지속 판단, 충분한 조건 유지, 새잎 찾기, 같은 표식 추적, 관찰 사진 계획, 실제 증거 스탬프, 자신의 새 질문을 다룬다. 반복 클릭 수를 채우는 방식으로 늘리지 않았다. 약1.5배는 설계 목표이며 실제 학생 플레이 시간을 측정하지 않았다.
- 기존 완료와 기록은 유지한다. 완료한 구역의 `새 발견 미션` 버튼으로 추가 활동에 들어가고, 중간 상태도 새로고침 뒤 이어진다.
- 빛 부족 회복은 긴 줄기를 유지한 새잎으로 노트·게임·기록·영상 모두 일치시켰다. 찍지 않은 동물 중간 사진을 학생 기록으로 만들지 않는다. 온전한 잎/닫힌 번데기는 참고 모형으로 표시하고 도토의 글 메모와 구분한다.
- 잘못 연결된 잎·장미를 투명 에셋으로 교체했다. care/seasons 개념 영상은 재렌더했고 중단 당시0.875초였던 seasons도12초로 복구했다. 렌더가 완성되기 전에는 기존 영상을 교체하지 않는다.
- 코르크판 터치 드래그 뒤 남은 pointerup이 같은 사진을 다시 빼던 오류를 수정했다. 낮은 가로 화면의 상단 목표와 판 제목 간격도 조정했다.
- 깨진/미지원 저장 원문은 자동 덮어쓰지 않는다. 다른 창의 변경과 오래된 초기화 확인은 차단한다. 기록함에서 현재 활동 JSON과 기존 원문TXT를 따로 보관하며, 앱에 가져오기 기능이 없다는 범위를 안내한다. 교사 시연은 학생 원본과 분리한다.
