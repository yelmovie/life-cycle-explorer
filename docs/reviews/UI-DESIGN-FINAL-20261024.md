# UI·타이포·태블릿 검증 — 2026-10-24

적용 기준: design, final-check의 scoring-21, tablet-check. 10점에서 FAIL −3 / WARNING −1로 시작하고, 결함을 없앤 뒤 추가 조건을 실제로 검증한 항목만 11점으로 판정한다.

## 범위와 증거

- 기존 전 화면: 각 활동·추가 발견·설정·노트·인증서 등 55개 상태. 필수 873×580 / 906×755 / 1280×800 / 1920×1080, 추가 1024×768 / 768×1024에서 총 328개 상태를 확인했다. 첫 873 프로필의 4개 캡처/탐색 시간 초과는 이후 재검증했다.
- 변경 후 집중 검증: 14개 대표 상태 × 위 6개 프로필 = 84개 상태. 지도, 확대 관찰, 그림 기록, 씨앗 성장, 돌봄 전후, 긴 이야기, 설정, 영상 목록의 해금·잠금, 인증서, 엔딩, 관찰 노트, 교사 단계 선택, 마지막 보상 모달을 포함한다.
- 추가 1440×900의 제목·지도·관찰 3개, 1280×720 전자칠판 하한 6개 상태를 확인했다.
- 자동 집계는 DOM 컨트롤의 겹침·화면 이탈·크기, Phaser 실제 입력 영역·글자 크기, 수평 넘침, 이미지 로딩, 브라우저 오류를 기록한다. 캔버스 내부 글자 가림은 별도 스크린샷으로 확인했다.
- 실제 입력 검증: 작은 알의 중심에서 22 CSS px 떨어진 곳을 잡아 드래그 성공, 세로·가로 회전 뒤 저장 원문 일치, 375px 초기 세로 안내의 화면 가림·입력 차단, 가로 복귀 확인.
- 교사 단계 선택은 실제 마우스와 터치로 네이티브 목록을 열었다. 열린 상태 `:open`과 화면 캡처를 확인하고, 목록에서 다른 활동으로 전환했다. DOM의 `selectOption()`만으로 통과 처리하지 않았다.
- 사용자의 실제 브라우저 저장소는 사용하지 않았다. 모든 재현은 별도 Chrome 테스트 컨텍스트에서 수행했다.
