2026-10-24. 현재 실행 경로인 field-content/flow/model, game-app, field-dialogs/concepts/record-art, 공통 사진 노트 및 개념 영상 생성 원본을 읽었다. expedition은 현재의 화면이 아닌 호환·저장 데이터 경로임을 구분했다. 아래는 코드·1차 자료 대조 결과이며, 버튼을 실제로 누르는 통합 검증은 별도 수행한다.

## 교육과정 기준

교육부 고시 제2022-33호의 공식 첨부 ZIP에서 별책9 과학과 HWP 원문을 직접 추출하여 3~4학년군 ‘생물의 한살이’를 확인했다. 4과04-01은 직접 관찰과 글·그림 표현, 02는 조건을 찾는 실험 설계·수행, 03은 다양한 한살이를 조사해 소개 자료를 만들고 공유하는 활동이다. 해설은 싹트기 비교를 물·온도, 자라는 조건을 물·햇빛으로 제한하고 식물 유형을 한해살이·여러해살이로 다룬다. 따라서 본 게임의 5개 구역 구성은 범위와 맞는다. 화면 모형 조작을 실제 생물의 장기 직접 관찰과 동일한 성취로 단정해서는 안 된다. 현재 실제 관찰 약속·모형 기록 표시를 유지한다. [교육부 고시·원문 첨부](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&search=)

## 무반응 버튼·중복 피드백 코드 점검

| 버튼·조작군 | 연결 확인 | 검증 한계/개선 |
|---|---|---|
| 나비 보기·돋보기 | 새 observe 이벤트→inspect 성공→노트 팝업 연결 API 제공 | 통합 담당자가 연결 후 실제 입력 확인 필요. 보기 버튼과 큰 생물 영역을 함께 제공 |
| 비교 실험 시작 | seed-run→준비·예상·한 조건 차이 검사→run 저장 | 실패 이유만 힌트로 숨기지 않고 상태·다음 할 일을 직접 표시하도록 새 화면 보강 |
| 날짜·시간 | time-stop, range, dial→seed-day/care-day/animal-time/season | 값 변경과 시각 애니메이션의 일치 여부는 실제 화면 확인 필요 |
| 네 종류 사진 | seed/care/animal/season-photo는 각각 상태 저장 액션 존재 | 성공 시 공통 카메라→셔터→사진 붙이기→자동 메모 팝업 API 제공. 저장 실패 시 성공 팝업 금지 |
| 그림·글 | drawing stroke, observation-note, save-note, clear-drawing 연결 존재 | 학생 글을 자동 모범답안으로 덮어쓰지 않음 |
| 실험일지·사진 설명 | book-record/move/caption/title/summary, save-caption, select change 연결 존재 | 같은 사진 상·하단 중복 및 패널 겹침은 새 코르크판 화면에서 정리 중 |
| 개념 영상 | 재생/일시정지/다시보기/시간 이동/닫기/마무리 리스너 존재, 실패 시 대체 설명 | 실제 영상 재생·오프라인 실패 대응은 통합 QA에서 확인 |
| 기록함·내보내기·설정 | 페이지 이동·개별 기록·PNG·백업·소리·미리보기·초기화 핸들러 존재 | 실제 파일 다운로드·모달 연속 열기는 통합 QA에서 확인 |

코드 읽기 범위에서는 버튼만 있고 대응 액션이 전혀 없는 정적 항목을 확정하지 못했다. 학습자의 다음 행동이 불명확하거나, 조건 미충족으로 변화가 없는 상황은 무반응처럼 보일 수 있으므로 준비 상태·직접 안내·성공 팝업을 함께 검증해야 한다.
