# Lane A — 교육·기능·코드 점검

점검일: 2026-10-14. 범위: `core.js`, `app.js`, `art.js`, `tests/core.test.js`, `docs/PRD.md`. 원시 코드·모형 테스트 기반 점검이며 브라우저 조작, 화면 검증, 최종 배포 판정은 통합 점검 담당에게 넘긴다.

역할·문제·목표는 홈/지도에 명시되어 있다. 필수 선택은 실험 조건, 비교 생물, 자료 선택이며 후속 모형·기록·결과물에 영향을 준다. 점수·속도 경쟁 없이 관찰·기록·설명·수집 근거가 해금을 결정한다.

문장 길이 검사는 빈 입력 방지이며 과학적 서술의 정답을 자동 판정하지 않는다는 한계가 PRD에 명시돼 있다. 오답 시 구역 밖으로 튕기는 로직은 없지만, 잘못 고른 조건/분류의 구체적 오류 설명은 대부분 힌트·비활성 다음 버튼 수준이다. 개별 오개념에 대한 교사 피드백을 대체하지 않는다.

## 실행과 범위

- 최초 기존 테스트: 14개 모두 통과. 실제 결함의 회귀 테스트 추가 후 최종 `npm test`: 20개 모두 통과.
- 최초 `npm run check`의 app/core/art JavaScript 구문 검사: 통과. 마지막 재실행은 병행 작업 중 package.json에 추가된 `scripts/build.mjs`가 아직 생성되지 않아 `MODULE_NOT_FOUND`로 중단됐다. 통합 담당의 파일 생성 완료 후 재실행이 필요하다.
- 저장 키 `life-clock-lab.mvp.1`과 `version:1` 유지. 기존 사용자 기록 구조 유지.
- 자동 저장 실패 시 상태 안내가 있으나, 실제 브라우저 저장 거부·새로고침·이어하기는 이 lane에서 미조작: `NOT TESTED`.
- PNG 내보내기 코드는 사용자 설명·요약·근거를 포함하고 Blob URL을 해제한다. 다운로드·새 이미지 적용 후 출력과 비율은 브라우저에서 확인 필요: `NOT TESTED`.
- 키보드 포커스, 브라우저 뒤로가기, 실제 입력기·터치, 음성/모달 접근성은 브라우저 검증 담당 범위: `NOT TESTED`.
- 정식 성취기준 코드/원문 대조 자료가 없어 A2 교육과정 원문 일치는 `NOT TESTED`. 프로젝트의 초등 3학년 한살이 목표와 활동 연결은 로컬 PRD와 대조했다.
- 점검 시작 시 이 폴더는 Git 저장소가 아니어서 브랜치·변경량 확인 불가. 전역 리팩터링 없이 승인된 `core.js`와 `tests/core.test.js`만 수정했다.
