# 놀이 화면 비율·중복 조작 정리 — 2026-11-18

공통 기준 `_shared/LAYOUT-BALANCE-DELIVERY-20261118.md`에 따라 생명 시계 연구실의 활동 화면 비율과 중복 조작 버튼을 측정하고 고쳤다. 이 프로젝트는 디자인 기준작이라 장면 안 패널(종이 카드·이젤·작업대가 배경 그림 위에 놓이는 구조)과 clamp 글자 토큰은 그대로 두었다. 학습 문구·판정·저장·진행 로직은 바꾸지 않았다.

측정: macOS, Node v24.22.2, 헤드리스 Chrome(Playwright). 개발 서버(4191) 교사 시연 경로로 모든 활동 단계를 열어 쟀다. 자료는 `.tmp/layout-balance-20261118/before|after/`(`report.json`, 화면별 스크린샷)에 있다.

## 1. 무엇을 "놀이 영역"으로 쟀나

이 게임은 활동 장면을 `field-scenes.js`의 `ROOM_VIEW`(월드 64..1248 × 140..740) 틀에 맞춰 위·아래 띠 사이에 넣는다(`configureViewport`·`hudInsets`). 작업대·이젤 같은 놓이는 자리는 배경 그림 안에 그려져 있고, 카드와 도구는 그 위에 놓인다. 그래서 다음 두 값을 함께 쟀다.

- **활동 틀**: `ROOM_VIEW`를 화면에 투영한 크기. 학생이 조작하는 물체가 모든 단계에서 이 안에 있다. 23개 단계 물체 외곽의 합집합은 월드 95..1230 × −7..755였다. 기준 수치는 이 값으로 판정한다.
- **물체 외곽**(참고): 단계마다 보이는 캔버스 물체와 장면 안 DOM 버튼의 외곽. 배경에 그려진 작업대·이젤은 포함하지 않는다. 그래서 실제로 눈에 보이는 활동 무대보다 작게 나온다.

## 2. 변경 전 진단

| 화면 | 1280×800 | 1024×768 | 1920×1080 |
|---|---|---|---|
| 위·아래 띠 사이 | 68.9% | 67.7% | 73.1% |
| 활동 틀 높이 / 면적 | 68.9% / 58.5% | 67.6% / 67.6% | 73.1% / 59.2% |
| 활동 틀 좌우 빈 띠 | 7.5% / 7.5% | 0 / 0 | 9.5% / 9.5% |
| 시간 조작 단계(씨앗 시간·계절 2단계) 활동 틀 | **62.4% / 48.0%** | 62.9% / 58.5% | 73.1% / 59.2% |
| 지도(화면 전체 그림) 띠 사이 | 73.0% | 72.4% | 78.0% |
| 대표 활동(나비 확대 관찰) 물체 외곽 높이 / 면적 | 64.7% / 50.4% | 63.5% / 58.2% | 68.7% / 51.0% |

원인은 세 가지였다.

1. **위·아래 띠의 빈 여백.** 활동 장면은 띠 사이 높이에 맞춰 커진다. 그런데 위 띠의 안쪽 여백이 12px+12px였다. 아래 띠에도 활동 화면에서는 띠 밖에 떠 있는 상태 문구(`#status`)의 빈 줄 간격 8px와 아랫 여백 16px가 남아 있었다. 그래서 1280×800에서 장면 높이가 70%에 못 미쳤다.
2. **아래 띠 두 줄.** 씨앗 시간·돌봄 뒤·동물 시간·계절 두 단계에서는 아래쪽에 시간 슬라이더와 「0일·중간·마지막」 같은 바로 이동 버튼이 함께 나왔다. 그래서 아래 띠가 두 줄로 커졌고, 1280×800에서 장면이 62.4%로 줄었다.
3. **1024×768(4:3)은 가로 폭에 묶임.** 활동 틀이 약 2:1이라 1024px 폭을 꽉 채우면 높이가 67.6%가 된다. 좌우 빈 띠는 0이다.

떠 있는 요소와 배경 가림: 종이 카드는 배경의 이젤·작업대·벤치 자리에 놓이고, 띠 위의 알약 모양 바는 반투명 유리 톤이다. 불투명한 큰 판이 배경을 덮는 화면은 없었다. 이 부분은 바꾸지 않았다.

## 3. 중복 조작 점검

활동 23단계와 지도·첫 화면에서 보이는 조작 요소를 JS로 모두 뽑았다(`before/report.json`의 `controls`). 창은 코드에서 `data-action="close"` 버튼을 쓰는 곳을 모두 찾았다.

| 유형 | 어디 | 처리 |
|---|---|---|
| 같은 동작 두 곳 (직접 조작 + 화면 버튼) | 씨앗 시간·돌봄 뒤·동물 시간·계절·같은 식물 찾기 5단계. 장면 안 생명 시계(손잡이 끌기·−/+·키보드 초점)와 아래쪽 슬라이더가 같은 값(`act(type,…)`)을 바꿈 | **아래 슬라이더 6개(동물 단계는 나비·개 2개)를 숨김.** 시계와 「0일·중간·마지막 / 첫봄…다음 봄」 바로 이동 버튼(✓ 기록 표시가 있어 정보가 다름)은 남김 |
| 같은 동작 두 곳 (닫기 + ✕) | 아래쪽에 「닫기·계속 탐험·계속 살펴보기·돌아가기·숲으로」(`data-action=close`)가 있는 창 12종: 기본 안내 창, 설정, 앞 탐사 먼저, 기록 보존 실패, 관찰 노트 안내, 씨앗 예측, 발견과 관찰 약속, 탐구 기록함, 기록 상세, 발견 이야기, 탐험 마무리, 수행 기록 | **모서리 ✕를 숨김.** 아래 버튼과 Esc로 그대로 닫힌다. 닫기 버튼이 없는 창(관찰 노트 책, 개념 영상, 인트로 영상, 캐릭터 대화)은 ✕가 유일한 닫기라 그대로 둠 |
| 같은 동작 두 곳 (판단 후 유지) | 지도: 빛나는 다음 구역 문 + 오른쪽 아래 「○○ 가기」 | **유지.** 문은 지난 구역을 다시 고를 때도 쓰는 위치 표시이고, 「가기」는 모든 화면에서 같은 자리인 주 버튼이다. 하나를 없애면 지도에서 "어디로?" 신호나 주 버튼 자리의 일관성이 깨진다 |
| 같은 안내를 여는 버튼 | 힌트는 활동마다 「도토 힌트」 하나뿐. 학생 모드에서 `next`가 힌트일 때는 이미 숨김 | 해당 없음 |
| 같은 무게 버튼 | 활동 아래 띠는 「도토 힌트」(왼쪽)·주 버튼(오른쪽 아래, 진한 색)·보조 버튼(밝은 색) 구조. 탐사 완료 화면의 「(선택) 새 발견 미션」「(선택) 개념 영상」은 보조 버튼 | 해당 없음 |
| 남은 옛 버튼 | 학생 화면에서 찾지 못함. 교사 시연 전용 「활동 바로가기」「자동 재생」「다음 활동으로 건너뛰기」는 교사 시연에서만 보임 | 해당 없음 |

합계: 중복 조작 18곳 정리(시간 슬라이더 6개 + 창 ✕ 12종), 1곳은 판단 후 유지(지도 문/가기).

## 4. 적용한 수정 (채택)

모두 새 파일 `src/layout-balance.css`에 넣었다. `game.css`는 다른 작업이 고치는 중이라 건드리지 않았다. 연결한 곳은 `index.html`, `scripts/build.mjs`의 배포 파일 목록, `server.mjs`의 개발 서버 파일 목록이다.

1. 활동·지도 화면의 위 띠 여백 12/12→8/6px, 줄 간격 8→6px, 목표 문구 상하 여백 8→6px. 아래 띠의 빈 첫 줄 간격 8→0, 아랫 여백 16→10px. 버튼 크기(48px 이상)는 그대로다. `hudInsets`가 띠의 실제 높이를 읽으므로 JS는 바꾸지 않았다.
2. `#controls .time-slider, #controls .time-sliders { display:none }`: 장면 시계와 겹치는 슬라이더를 숨긴다.
3. `dialog[open]:has(>.dialog-actions [data-action=close])>.close { display:none }`: 아래에 닫기 버튼이 있는 창에서만 ✕를 숨긴다.

교실 QA 스크립트도 이 변경에 맞췄다.
- 대상: `scripts/qa-field-play.mjs`, `qa-recovery-play.mjs`, `qa-field-regression.mjs`, `qa-classroom-media.mjs`.
- 숨긴 슬라이더는 `range()` 도우미가 같은 `change` 이벤트로 값을 한 단계씩 바꾼다.
- 창 닫기는 `dialog [data-action=close] >> visible=true`로 누른다.

## 5. 채택하지 않은 안

- **`ROOM_VIEW` 좁히기(1024×768을 70%로).** 23단계 물체의 합집합이 이미 틀 끝(95..1230)까지 닿아 있다. 틀을 좁히면 씨앗 준비·나비 확대 관찰의 카드가 화면 끝에 닿거나 잘린다. 1024×768은 좌우 빈 띠가 0이고 띠 사이 70.7%의 96%를 활동 틀이 쓰므로, 기준표의 "위·아래 띠 제외 나머지 거의 전부"로 보고 예외로 둔다.
- **단계마다 물체 외곽에 맞춰 카메라 다시 맞추기.** 물체 외곽이 작은 단계(이름표·동물 단계 높이 52~56%)를 키울 수 있다. 하지만 장면을 두 번 그려야 하고, 단계마다 배율이 바뀌어 글자 크기와 손 위치가 흔들린다. 배치 구조를 바꾸는 큰 수정이라 제안만 남긴다.
