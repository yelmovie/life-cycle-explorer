# Phaser 0.4.0 구현·기능향상 기록

## 출발점과 결과

초기 설계 공유 대화의 5구역/10화면, 지훈·잎새, 탐구 기록으로 생명 시계를 복원하는 서사를 실제 Phaser 장면으로 옮겼다. 3D 제안은 최신 요청에 맞춰 2D 단면·독립 시간축·조건 장치로 구현했다. 기존 v3 탐구 상태와 자산은 재사용하고 별도 진입점·저장키를 사용한다.

태블릿이 필요한 행동은 확대 부위와 핀의 연결, 시간 이동과 조건별 변화, 재실험 비교, 같은 식물 개체의 계절 추적, 자기 기록으로 만드는 움직이는 발표이다. 분류 정답만 누르는 흐름이 되지 않도록 증거·관찰 문장·설명·수정 기록을 완료 조건에 연결했다. 문장의 내용 평가는 교사의 역할로 남겼다.

## 구조와 데이터

Phaser 3.90.0의 1280×610 장면을 FIT 방식으로 가로 공간에 맞춘다. 고정 헤더·현재 행동·장면·도구·다음 행동의 다섯 구역이며 학습 화면 자체의 문서 스크롤을 없앴다. 기록함과 긴 설명만 별도 대화상자를 쓴다. 모달 중에는 장면 입력·타이머를 정지한다. 기본 장면을 유지하고 학습 대상만 갱신하며 이전 타이머·트윈·렌즈 마스크·기록 텍스처를 정리한다.

`game-model.js`는 inquiry-core의 완료 판정과 증거 모델을 연결한다. 같은 관찰 슬롯을 반복 저장하면 기존 증거를 갱신하므로 필수 기록 공간이 소진되지 않는다. 완료한 실험 조건은 잠그고 재실험은 새 실행 기록을 만든다. 돌봄 버튼을 다시 눌러도 경과 시간과 관찰 기록을 잃지 않는다.

`life-clock-lab.phaser.4`는 상태 버전 3을 보관한다. 이전 `life-clock-lab.adventure.3`/`.2`에서 읽은 기록은 복사하고 원본 저장키는 수정하지 않는다. 저장 접근 차단·용량 부족은 앱을 중단시키지 않고 안내한다. 새 탐험은 확인 단계를 거친다.

자기 기록을 `game-records.js`가 실제 이미지로 재구성한다. 스튜디오와 PNG에는 선택한 그림·핀·조건·전후 비교가 반영된다. 종 대표 그림만 사용했던 이전 표시를 바꿨다. PNG는 생성된 Blob을 미리 보여 주고 사용자가 내려받는다.

## 자산과 배포

화면용 이미지 60개의 합계는 6,191,518 bytes이며 원본 대응 파일 합계는 9,967,916 bytes였다. 전후 치수는 `assets/game/manifest.json`에 있다. 시작 시 지도·잎새·기본 화분·걷기 시트만 적재하고 각 활동에 필요한 자산을 뒤에 불러온다. 같은 URL의 텍스처는 한 키로 공유하고 지난 활동의 불필요한 텍스처는 해제한다. 이는 실제 저사양 기기의 메모리·FPS 측정을 대신하지 않는다.

`npm run build`는 현재 모듈과 참조 자산·Phaser 라이선스만 `dist/`에 복사한다. 기존 원본과 이전 코드·문서는 포함하지 않는다. 이전 배포 폴더에 오래된 파일이 있으면 삭제 대신 `build-archive/`에 보존한다. 로컬 서버는 루프백에만 바인딩하고 런타임 경로만 제공한다. 외부 정적 호스팅의 보안 헤더는 해당 호스팅 설정이 별도로 필요하다.

도입 15초·엔딩 22초의 [영상 제작 캔버스](https://chatgpt.com/space/page_5ae3aacdd760819188b087223d50cc5c)를 별도로 작성했다. 샷마다 구도·각도·하나의 카메라 움직임·길이·끝 프레임을 지정했다. 현재는 영상 파일과 재생 연결이 없으며, 영상 없이 전체 활동을 완료할 수 있다.

## 검증과 남은 범위

브라우저 실제 입력으로 10개 활동을 완주하고 잘못된 조건·돌봄·분류의 수정, 여러 시점의 새로고침, 자기 기록 재생, 1800×1240 PNG 미리보기를 확인했다. 상세 결과와 화면별 제약은 [최종점검](reviews/FINAL-CHECK-20261018.md)에 기록한다. 외부 배포·학교망·물리 태블릿 터치·실제 학습효과 실험은 수행하지 않았다.
