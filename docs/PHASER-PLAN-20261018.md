# 생명 시계 연구실 · 태블릿 Phaser 고도화 계획

2026-10-18 · 5스테이지 × 2학습 화면. 2D 탐험 지도는 별도 공통 공간.

## 확인한 원문과 우선순위

[초기 설계 공유 대화](https://chatgpt.com/share/6ad4ae9d-3aa0-83e8-849a-98b216074114)를 브라우저에서 열어 제목과 본문을 확인했다. 8월 21일 최초 아이디어·3학년 기준 정리·5스테이지/10화면 통합, 8월 24일 3D 적용 논의, 8월 27일 퀘스트 강화, 9월 23일 가로형·캐릭터·글자 없는 배경 요청을 읽었다. 첨부 v2 MD는 파일 열기 버튼까지 확인했으며 본문 미리보기가 표시되지 않아 별도 문서의 내용을 읽었다고 간주하지 않는다.

최신 요청인 2D Phaser·태블릿 가로형을 우선한다. 이전 3D 제안의 교육적 목적은 2D 단면·시간 조작·장치 설치로 구현한다. 기존 v3 탐구 로직과 자료, 그림을 재사용하며 저장 기록과 원본은 보존한다.

원문의 핵심은 단순 OX/순서 맞히기가 아니라 관찰→증거→예측→실험→시간 변화→비교→소개 자료이다. 퀘스트→증거→세계 변화→최종 보고서→복원 미션→엔딩→수행 기록의 연결을 게임에 드러낸다.

## 화면 규격

- 우선 검증: 1280×800, 1024×768 가로형. 기본 학습 화면의 문서 세로 스크롤 0.
- 상단: 지도/이전 아이콘, 장소·현재 행동 한 줄, 기록함·설정. 안내의 반복 배치 금지.
- 중앙: 화면의 대부분을 차지하는 Phaser 장면. 작은 카드 더미보다 큰 대상 1~2개.
- 하단: 현재 도구 3~5개, 필요한 경우 시간 조작, 진행 행동 1개. 아이콘에 짧은 이름·접근성 이름 제공.
- 지훈·잎새는 장면 안에서 안내·증거 보관·반응 역할. 항상 긴 설명 패널을 차지하지 않는다.
- 긴 설명은 도움말에, 글 입력은 한 번에 한 기록만 편집. 기록함은 페이지 단위로 보여 준다.
- 터치 48px 이상, 핵심 안내 18px 이상. 색만으로 완료·오답을 구분하지 않는다.
- 캔버스는 게임 대상·이동·드래그·관찰·애니메이션을 맡고, DOM은 읽기·버튼·입력·모달을 맡는다.

## 학습 판정

[4과04-01] 관찰·글/그림, [4과04-02] 조건 통제·실험·재실험, [4과04-03] 다양성 비교·자료 제작·공유에 대응한다. 앱의 관찰은 모의 자료이며 실제 사육·여러 날 직접 관찰을 대체하지 않는다.

예상은 틀려도 감점하지 않는다. 공정하지 않은 비교에는 이유를 주고 수정시킨다. 식물 키만으로 건강을 판정하지 않는다. 생물마다 단계 수와 소요 시간이 다르며 서로 다른 종을 동일 날짜로 동기화하지 않는다. 봉선화 다음 세대와 같은 사과나무를 구별한다. 자유 문장의 과학적 타당성은 자동 채점하지 않는다.

보상은 정답 속도·클릭 수가 아닌 관찰 근거·재실험·수정·표현에 붙인다. 장비는 다음 구역에서 실제로 사용한다. 오답으로 이전 진도나 기본 획득물을 잃지 않는다.

## 구현 범위와 순서

1. 별도 Phaser 진입점과 공통 화면 틀, 상태·저장·기록 연결을 준비한다.
2. 지도와 10개 장면을 구현한다. 기존 inquiry-core의 검증된 탐구 상태를 재사용한다.
3. 기록 재생·PNG·세계 변화·최종 성취를 연결한다. 필요한 신규 그림만 생성한다.
4. 도입/엔딩 영상은 제작 요청 캔버스로 분리한다. 영상 없이도 학습과 엔딩 완료가 가능해야 한다.
5. 가로 태블릿 두 크기에서 조작·새로고침·오답 수정·완주·출력·콘솔·빌드를 확인한다.

외부 공개 배포는 이번 작업에 포함하지 않는다. 실제 터치 하드웨어·학교망 검증은 브라우저 화면 크기 검증과 구분해서 보고한다.
