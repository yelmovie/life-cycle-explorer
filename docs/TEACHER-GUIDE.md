# 교사용 안내 — 생명 시계 연구실 (2026-11-22)

## 1. 한 줄 소개

지훈·잎새·다람쥐 도토와 숲을 걸으며 나비·씨앗·온실 식물·사계절 정원의 한살이를 관찰하고 비교하는 태블릿용 웹게임입니다.

## 2. 대상

- 학년·학기: 초등 3학년 1학기(운영 시트 「이예리 선생님」 탭, 2026-11-22 확인)
- 과목·단원: 과학, 「생물의 한살이」(운영 시트 단원명).
- 성취기준(`src/settings-content.js` `standards`):
  - [4과04-01] 동물의 한살이를 직접 관찰하고, 관찰한 내용을 글과 그림으로 표현할 수 있다.
  - [4과04-02] 식물이 자라는 데 필요한 조건을 찾는 실험을 설계하여 수행할 수 있다.
  - [4과04-03] 생물의 한살이 과정을 조사하여 생물에 따라 한살이의 유형이 다양함을 소개하는 자료를 만들어 공유할 수 있다.
- 구역과 성취기준의 연결 표는 저장소에 없습니다. 확인 필요.

## 3. 준비

- 기기: 태블릿과 전자칠판의 가로 화면에서 씁니다(`docs/PRD.md`). PC도 됩니다.
- 소리: 배경 음악, 효과음, 목소리가 있습니다. 설정에서 따로 끌 수 있고, 소리 없이도 모든 활동을 할 수 있습니다.
- 예상 시간: 확인 필요. 40분 수업 분량은 아직 시험하지 않았습니다(`docs/reviews/SCORE-20261121.md` B16).
- 네트워크: 한 번 열면 오프라인에서도 열린 활동과 저장이 됩니다. 새 구역 그림은 연결이 있어야 불러옵니다(`HANDOFF.md`).

## 4. 차시 흐름

시작 화면 → 인트로 영상 → 숲 지도에서 구역 선택 → 구역마다 단계 활동 → 생명 시계탑 → 엔딩과 인증서 순서입니다. 구역마다 개념 영상(12초)이 있습니다.

| 구역 | 학생이 하는 일 | 배우는 개념 |
|---|---|---|
| 1 나비의 숲 | 알·애벌레·번데기·어른벌레를 확대해 보고 글로 적고, 사진을 자라는 순서로 놓고, 새 알을 놓습니다. | 모습이 달라져도 한살이가 이어집니다. |
| 2 씨앗 연구소 | 같은 흙·콩으로 두 화분을 준비하고 물 또는 온도 한 가지만 다르게 해서 싹을 비교합니다. | 한 조건만 다르게 해야 공정한 실험입니다. |
| 3 햇살 온실 | 물기와 빛을 재고, 잎·흙의 신호를 찾아 돌보고, 돌보기 전후를 비교합니다. | 식물의 신호를 측정과 함께 읽습니다. |
| 4 사계절 정원 | 두 동물의 자라는 시간을 보고, 이름표로 겨울과 다음 봄의 식물을 비교하고, 새 식물 카드를 나눕니다. | 같은 생물과 다음 세대를 구별하고, 한해살이·여러해살이를 나눕니다. |
| 5 생명 시계탑 | 앞 네 구역의 내 사진에서 증거를 찾고, 발견과 관찰 약속을 쓰고, 시계를 돌립니다. | 내 기록을 근거로 설명합니다. |

## 5. 정답과 판정 기준

글쓰기 칸(관찰 기록, 발견 문장, 관찰 약속, 다음 궁금증)은 정해진 정답이 없고, 글자 수 같은 형식만 확인합니다. 내용은 교사가 확인합니다. 아래는 정답이 있는 활동입니다(`docs/TEACHER-REVIEW-20261121.md`).

| 구역 | 활동 | 정답 또는 통과 조건 |
|---|---|---|
| 1 | 확대 관찰 | 네 모습을 한 곳 이상씩 확대하면 통과합니다. |
| 1 | 시간 필름 | 알 → 애벌레 → 번데기 → 어른벌레 |
| 1 | 다음 세대 | 새 알을 새 잎 자리에 놓습니다. |
| 1 | 숲의 흔적 탐정 | 도토의 먹이 메모는 애벌레, 날개 메모는 어른벌레에 연결합니다. |
| 2 | 같게 준비 | A·B 모두 같은 흙과 콩 세 알 |
| 2 | 조건 바꾸기 | 물 실험은 B에만 물 주기, 온도 실험은 B만 22°C로 올리기. 예상은 채점하지 않습니다. |
| 2 | 결과 살펴보기 | 꼬리표 「물을(온도를) 다르게 했어」를 화분 B에 붙입니다. |
| 2 | 공정한 실험 수리공 | 「A도 22°C로 맞추기」를 고르고 수리한 설계를 저장합니다. |
| 3 | 신호 찾기 | 화분 1(물 부족)은 흙·마른 흙과 잎·처진 잎 둘 다, 화분 2(빛 부족)는 잎·옅어진 잎빛입니다. |
| 3 | 맞춤 돌봄 | 화분 1은 알맞게 물 주기(물기 막대가 알맞음이 될 때까지), 화분 2는 빛이 드는 곳으로 옮기기 |
| 3 | 변화 비교 | 화분 1은 「축 처졌던 잎이 다시 섰어」, 화분 2는 「새로 자란 잎이 더 초록빛이야」 |
| 3 | 새잎 돌봄 탐정 | 물·빛 그대로 두고 관찰, 새잎의 초록빛에 표시합니다. |
| 4 | 다음 세대(동물) | 부모와 다른 생명 |
| 4 | 이름표 달기 | A-01은 사과나무, B-01은 봉선화 |
| 4 | 작년 식물 찾기 | 사과나무는 「작년 그 식물」, 봉선화는 「새로 자란 식물」 |
| 4 | 새 상황 카드 | 장미는 여러해살이, 콩과 해바라기는 한해살이 |
| 5 | 증거 찾기 | 확대 관찰 사진, 물 또는 온도 비교 실험, 시든 화분 또는 빛이 부족한 화분 돌봄 기록, 이름표를 단 사과나무 또는 봉선화와 다음 세대를 고릅니다. |

틀리면 정답을 바로 알려 주지 않고 다시 살펴볼 단서를 줍니다.

## 6. 수업 팁

- 자주 막히는 곳: 확인 필요. 실제 학생 수업을 아직 하지 않았습니다(`SCORE-20261121.md`).
- 되묻기 좋은 질문(앱 문항에서 가져옴):
  - 두 화분에서 무엇을 다르게 했고 무엇을 같게 했나요?
  - 잎이 처진 까닭을 모습만으로 정할 수 있을까요?
  - 겨울의 나무와 다음 봄의 나무는 같은 식물일까요, 새로 자란 식물일까요?
- 사용법: 앱의 교사용 안내처럼 한 단계씩 함께 읽고 학생이 본 것과 까닭을 먼저 묻습니다. 서로 다른 예상은 오답으로 끝내지 말고 비교와 다시 확인으로 이어 갑니다. 설정의 「탐구 기록함」에서 학생 기록을 함께 봅니다. 교사용 도구의 「모든 단계 한 번에 열기」는 시연용이며 학생 기록을 바꾸지 않습니다.

## 7. 저장과 다시 하기

- 진행과 소리 설정은 이 브라우저에만 저장됩니다. 서버로 보내지 않습니다.
- 사이트 데이터를 지우면 기록이 사라집니다.
- 처음부터 다시 하려면 설정의 「탐험 기록 초기화」를 누르고 「기록 지우기」를 확인합니다. 소리 설정은 남습니다. 시작 화면에도 「처음부터 다시 하기」 버튼이 있습니다(보이는 조건은 확인 필요).

## 8. 알려진 한계

- 실제 학생 반응, 40분 수업 분량, 실물 태블릿 터치와 저사양 기기는 시험하지 않았습니다(`SCORE-20261121.md`).
- 화면 속 시간과 생장은 비교를 돕는 모형입니다. 실제 생물과 속도가 다릅니다. 글자 수와 게임 완료는 이해 여부를 보여 주지 않습니다.
- 교사 검토지(`docs/TEACHER-REVIEW-20261121.md`)에 「확인 필요」 6건이 남아 있습니다. 낯선 낱말 「개체」, 온도 실험 정답 문장의 조사, 빛 부족 화분의 정답 문장, 「부모와 같은 몸」 표현, 콩 카드의 단서, 화면에 나오지 않는 뱀 카드입니다.
