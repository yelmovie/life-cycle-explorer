# MVP 검증 기록

검증일: 2026-09-23 · 로컬 앱: http://127.0.0.1:4186

## 통과

- `npm run check`: app.js / core.js / art.js 문법 검사 통과.
- `npm test`: 12개 핵심 로직 테스트 통과.
- 실제 브라우저 UI로 새 연구에서 10번 미션 최종 엔딩까지 완주.
- 미완료 구역의 잠금과 장 완료 후 다음 구역 개방 확인.
- 관찰핀 3개 및 메모 입력, 125% 확대, 새로고침 후 핀/메모 복원 확인.
- 서로 다른 회차 비교 및 근거 입력 후 진행 확인.
- 물과 온도가 모두 다른 실험 차단, 질문에 맞는 한 조건만 변경하면 실행 가능 확인.
- 0일/7일 관찰 시점 저장과 A/B 결론 입력 확인.
- 빛/수분 센서 설치, 조건 선택, 성장 주장과 관찰 근거가 불일치하면 진행 차단 확인.
- 동물/식물 각각 두 개 기준 비교 기록, 6개 생물 분류/근거, 장미 전이 사례 완료 확인.
- 수집한 관찰과 실험 자료로 장면 3개 생성, 제목/설명/요약 입력, 장면 순서 변경 확인.
- PNG 실제 파일 생성 확인: 1600×830, 165,363 bytes. 이미지 파일을 직접 열어 한글, A/B 그림, 설명, 근거, 요약의 정상 표시 확인.
- 5개 링 결합과 최종 완료 안내, 완료 후 지도 복귀 확인.
- 테스트 중 브라우저의 수집된 error/warn 로그 없음.
- 초기화 확인 창을 거쳐 테스트 진행 데이터를 지우고 메인 시작 화면으로 복귀.

## 반응형 DOM 실측

| 폭 / 높이 | 제작소 가로 넘침 | 관찰 화면 가로 넘침 | 보정 후 관찰 화면 48px 미만 버튼 |
|---|---|---|---|
| 375×800 | 없음 | 없음 | 없음 |
| 768×800 | 없음 | 없음 | 없음 |
| 1024×768 | 없음 | 없음 | 없음 |
| 1280×800 | 없음 | 없음 | 없음 |
| 1440×800 | 없음 | 없음 | 없음 |

제작소의 작업 영역, 기록 영역, 상단 바 내부에서도 가로 넘침이 없음을 확인했다. 작은 너비에서 일부 버튼 폭이 48px 미만인 점을 발견하여 수정했다. 분류/기록 편집 중 전체 화면 재렌더로 내부 스크롤이 초기화되던 부분은 동일 화면의 스크롤과 선택 필드 포커스를 보존하도록 수정했다.

## 검증 제한

- 브라우저 화면 스크린샷 도구가 반복적으로 timeout을 반환해 앱 전체 화면의 픽셀 단위 시각 검수는 완료하지 못했다. 위 레이아웃 결과는 DOM 실측이며 스크린샷 검수와 구분한다. 제공 배경·캐릭터 시트·타이틀과 실제 출력 PNG는 이미지로 직접 확인했다.
- 브라우저 도구의 download 이벤트는 timeout이었지만 Windows 다운로드 폴더에서 실제 PNG 파일 생성 및 내용을 확인했다.
- 실제 태블릿 두 손가락 핀치, 전자칠판, Safari, 저사양 기기의 성능/FPS는 미검증이다.
- 자유 서술 내용의 타당성은 자동 채점하지 않는다. 수업 적용 전 교사의 내용 검토가 필요하다.
- 모든 화면과 모든 크기의 조합에 대한 완전한 시각/접근성 검수, 수업 현장 사용성 검증은 아직 수행하지 않았다.

## 상단 공통 메뉴 후속 검증

- 홈/이전/소리/설정 네 아이콘이 10개 미션 모두에 존재함을 실제 브라우저에서 확인.
- 관리자 스위치 하나로 5개 구역 동시 개방, 미완료 10개 페이지 자유 이동 확인.
- 해제 시 기존 진행 잠금 복원 및 잠긴 현재 화면에서 지도 복귀 확인.
- 이전 버튼으로 10번에서 실제 직전 방문한 9번 페이지로 복귀 확인.
- 음소거 후 새로고침하여 설정 유지 확인. 테스트 후 소리 켜짐/전체 해금 꺼짐으로 복귀.
- 375/768/1024/1280px에서 상단 가로 넘침 없음, 네 아이콘 모두 48×48px.
- 이번 후속 작업에서는 스크린샷 도구가 정상 작동하여 1024×768 화면의 상단 아이콘 배치를 시각 확인함.
- 핵심 테스트는 관리자 해금/기존 저장 호환 2건을 더해 총 14개 통과.
