## 외형과 등장

**뒤감기 시계 / 큰 태엽 키와 톱니 한 개, 나비 모양 시계 장식.** 스테이지 완료 기록 후 지도에 돌아올 때 해당 장소 옆에 등장한다. 기존 주인공·동료·건물의 스타일을 유지하고, 악당과 소품의 접점이 글 없이도 읽히게 그린다. 아래 소품 동작은 지도 위 짧은 장난 컷이다. 활동 화면이나 기존 학습 데이터에는 손대지 않는다.

기존 지도 악당 상태와 저장 정규화 확인. 단원 기록과 생물의 실제 성장 장면에 역재생을 적용하지 않는다.

## 스테이지마다 바뀌는 소품·자세·대사

장소명은 기획상의 연결 기준이다. 활성 버전의 스테이지 ID와 이름을 대조한 뒤 키를 정한다. 선택 구역은 실제 별도 완료 이벤트가 있을 때만 추가한다.

| 장소 | 악당 스프라이트 동작 | 첫 등장 또는 접근 대사 예시 |
|---|---|---|
| 나비의 숲 | 나비 순서 그림을 뒤집기 | “첫 장은 맨 뒤로!” |
| 씨앗 연구소 | 씨앗 표찰을 시계판 뒤에 숨기기 | “이 표찰은 잠깐 쉬는 중!” |
| 햇살 온실 | 온실 시계 손잡이 붙잡기 | “시곗바늘은 여기서 멈춰!” |
| 사계절 정원 | 계절 판을 한 칸 되돌리기 | “계절도 한 칸 뒤로!” |
| 생명 시계탑 | 커다란 톱니를 빼고 태엽 흔들기 | “톱니 하나면 탑이 멈추지!” |

상황 대사 예시:

- 접근: “시계 한 칸만 되돌려 볼까?” / “아직 내 태엽은 쌩쌩해!”
- 1·2타: “앗, 바늘이 튀었어!” / “태엽이 헛도네!”
- 퇴장: “이제 시간이 제대로 가겠네!” / “태엽 감으러 가야겠다!”

스테이지 고유 문장을 우선하고, 상황 대사는 연속 반복 없이 고른다. 주인공·보조 캐릭터의 주민 대화와 겹칠 때는 악당 말풍선을 생략한다.

## 세 번의 타격과 접촉 피격

| 사건 | 이 프로젝트의 표현 |
|---|---|
| 1타 · 짧은 명중 | 시곗바늘이 한 칸 튐 |
| 2타 · 더 큰 반동 | 태엽이 반 바퀴 헛돎 |
| 3타 · 마무리와 퇴장 | 스프링이 풀리며 시계 악당만 빙글 돌아 축소 |
| 주인공 접촉 | 주인공은 한 박자 굳었다 한 걸음 물러남 |
| 보조 캐릭터 접촉 | 동료는 머리를 낮췄다가 리듬 있게 튀어 오름 |
| 악당의 접촉 공격 동작 | 태엽 키를 한 칸 돌린 뒤 바늘 쪽 몸체가 앞으로 짧게 튀어 나옴. |
| 타격·퇴장 효과음의 차이 | 틱 → 덜컥 → 따르르 |
| 접촉 효과음 모티프 | ‘틱-텅’ |

세 타격은 같은 공격 입력이다. 가까이 있는 상태에서 한 입력이 한 타로 계산된다. 접촉 피격은 닿은 쪽만 재생하고 공격 카운트와 학습 진행에는 영향을 주지 않는 것을 권장한다. 소리를 꺼도 표정·자세·게이지로 읽혀야 한다.

## 방향과 시선

[공통 방향 규칙](../../_shared/MAP-VILLAINS-HANDOFF-20261114.md#방향시선공격-자세)을 적용한다. 시곗바늘과 계절판이 좌우 반전으로 역회전처럼 보이지 않게 소품을 별도로 둔다. 악당 얼굴과 몸만 먼저 돌아선다.

## 제작하고 적용할 순서

1. 기존 진입점 확인: [src/field-mission-data.js](../src/field-mission-data.js) · [src/map-villains.js](../src/map-villains.js) · [src/game-model.js](../src/game-model.js). 활성 지도와 완료 상태, 실제 주인공/보조 지도 원본·이름, 기존 악당/스프라이트·대사·저장부터 확인한다.
2. 기본 악당 한 장, 위 표의 장소별 소품 동작 스트립, 공통 이동/접촉 전조/피격/퇴장 프레임을 제작한다. 주인공·보조 피격은 각각 4~6프레임. 소품이나 배경을 몸통 시트에 같이 구워 넣기 전에 지도 크기에서 알아볼 수 있는지 확인한다.
3. 별도 승인된 구현 단계에서 완료된 장소 좌표에 악당을 붙이고, 기존 HUD 근처에서 공격·타격·피격·퇴장만 연결한다. 기존 이동/화면 전환/복구 상태와 학습 완료/다음 장소 해금은 보존한다.
4. 완료 전/후, 정확한 3타, 두 아군의 개별 접촉, 퇴장 및 재진입, 빠른 연타, 무음·모션 감소·태블릿을 확인한다. 가장 작은 정상 지도 표시 크기에서 소품과 방해 동작이 구분되는지 본다.

완료된 것: 정적 이미지 합성과 계획. 남은 것: 기존 시트/캐릭터 일치 확인, 프레임 제작, 대사 최종화, 구현 및 테스트. 06 물의 상태 변화는 참고 전용.
