# 0.7.0 · 개념 영상과 교실 UX 개선

2026-10-22. 기존 다섯 탐사의 증거 판정·저장 키·보상 조건을 유지하며 영상, 동물 조력자, 조작 피드백과 화면 균형을 개선했다.

## 개념 영상

| 파일 ID | 학습 개념 | 0~4초 | 4~8초 | 8~12초 |
|---|---|---|---|---|
| butterfly | 나비의 한살이와 다음 세대 | 알→애벌레 | 번데기→어른벌레 | 낳은 알에서 새 세대 |
| seed | 발아와 공정한 비교 | 같은 재료와 조건 비교 | 물·알맞은 온도와 발아 | 다른 조건을 같게 유지 |
| care | 증거에 따른 돌봄 | 물 부족·빛 부족 비교 | 원인에 맞는 돌봄 | 시간 뒤 새잎과 전후 비교 |
| seasons | 다양한 한살이·개체 추적 | 나비와 개의 다른 과정 | 사과나무의 줄기와 겨울 | 봉선화 씨앗에서 새 개체 |
| evidence | 증거로 설명·실제 관찰 | 관찰·실험·사진 | 내 기록 연결 | 실제 생물 관찰로 이어가기 |

`ai-video-prompt` 가이드를 적용했다. 각 구간은 고정된 정면 도해 카메라, 전체 비교 구도를 유지하는 정지 샷이다. 움직임은 도해 내부의 등장·화살표·생장·교차 전환으로 제한하고 마지막 1.2초는 최종 구도를 유지한다. 사람은 등장하지 않으며 생물 그림은 프로젝트 원본을 일관되게 재사용한다.

제작은 `scripts/render-concepts.mjs`의 SVG 프레임 → sharp → FFmpeg. 960×540, 24fps, 각 12초, 무음. H.264 MP4(yuv420p/faststart), VP9 WebM, 마지막 장면 WebP를 `assets/concepts/`에 제공한다. 영상의 한국어 글자는 DOM 자막·범례이며 화면 크기에 따라 확대된다. 영상 제작 도구는 배포하지 않는다.

완료 버튼을 누르면 해당 영상이 열린다. 완료 화면의 개념 영상 버튼으로도 다시 볼 수 있다. 닫기·계속하기로 항상 빠져나올 수 있고, 영상 시청 여부는 보상이나 다음 구역을 잠그지 않는다. 동작 줄이기에서는 직접 재생하며, 오류·8초 대기 시 포스터와 핵심 문장으로 대체한다. 닫기·다른 팝업·탭 숨김 시 미디어와 타이머를 정리하고 BGM을 분리한다.

## UI와 조작

- 숲·크림·황동 팔레트와 로컬 Jua를 유지했다. 의미 토큰의 글자 크기와 48px 이상의 조작 영역을 사용한다.
- 공통 dialog는 콘텐츠 높이에 맞춰 화면 중앙에 배치한다. 제목·본문·하단 버튼을 나누며 필요한 본문만 스크롤한다.
- 예상은 2열 선택지, 시간은 큰 날짜·계절 버튼과 기존 슬라이더, 사진을 남긴 시점은 체크 표시다.
- 기록함은 6개씩 페이지 이동, 가방은 2열, 기록증은 요약 머리말과 2열 내용으로 긴 스크롤을 줄였다.
- 지도 방향판이 캐릭터를 가리지 않게 옮겼다. 현재 탐사·단계·완료 상태를 상단에 표시한다.
- 다람쥐 도토는 지훈을 따라 걷고, 모든 활동 단계에 짧은 2단계 힌트와 조작 위치 강조를 제공한다. 정답 자리만 강조하지 않고 연결 가능한 자리를 보여 준다.
- 나비 필름은 실제 학생 순서로 연속 재생한다. 씨앗의 날짜를 직접 오가며 비교 사진을 남기고, 온실에서는 이틀 뒤 전후 비교 손잡이를 밀 수 있다. 계절 기록도 사진 체크와 함께 추적한다.
- 이야기판의 작은 사진에서 축소된 설명문을 빼고 실제 관찰 표시·그림·실험 결과를 크게 보인다. 전체 기록과 PNG의 세부 내용은 보존한다. 완성한 이야기는 직접 넘기거나 4초 간격으로 재생한다.

## 소리와 동물 에셋

Kenney 공식 [Interface Sounds](https://kenney.nl/assets/interface-sounds), [Impact Sounds](https://kenney.nl/assets/impact-sounds)의 CC0 효과음 10개를 로컬 WAV로 준비했다. 선택·놓기·관찰·사진·성공·보상·질문·시간·풀밭 발걸음을 구분한다. 첫 조작 뒤 로드하며, 효과음 끄기·탭 숨김·영상 중 정지와 합성 대체를 제공한다. 원본 파일 대응·SHA-256은 `assets/audio/manifest.json`, 원문 고지는 같은 폴더의 LICENSE 파일에 있다.

도토는 내장 image_gen으로 생성했다. 알파를 보존한 `assets/field/doto.webp`는 420×440, 원본은 `assets/field/source/doto-20261022.png`다. 생성 프롬프트와 출력 ID는 `assets/field/doto-generation.json`에 기록한다. 원본과 FFmpeg는 실행 빌드에 포함하지 않는다.

## 검증

- 기존 학습·저장·설정·이동 단위 검사 101개.
- 첫 시작부터 다섯 탐사·영상·엔딩·실제 기록책 PNG·기록증 PNG·새로고침 완주.
- 기본 화면 42개(6해상도), 공통 팝업 15종×3해상도, 영상·설정 6해상도 및 영상 오류·동작 줄이기·미디어 정리 검사.
- 최종 `dist`에서 기본 화면 42개, 팝업 45개, 미디어 검사 20개, 터치·보존 검사 7개가 오류 없이 통과했다. 영상 끝 포스터·다시 재생과 HTTP 범위 요청(206/416), MP4/WebM 10파일의 전체 디코딩도 확인했다.
- 터치 에뮬레이션으로 도구 선택·끌기·이야기 담기·시간 버튼·전후 비교 손잡이와 기록증 보존을 확인했다.
- `scripts/qa-field-play.mjs` → `npm run check:classroom`으로 다시 확인한다. QA는 격리된 Chrome 브라우저 저장소를 사용한다.
- 1920×1080, 1366×768, 1280×800, 1024×768, 1024×600, 873×580 등을 사용한다. 실제 태블릿·전자칠판 기기에서의 터치·스피커, 학교망 동시 접속은 별도 확인이 필요하다.

현재 실행은 `npm start`, 배포용 파일은 `npm run build`의 `dist/`. 외부 공개 배포는 수행하지 않았다.
