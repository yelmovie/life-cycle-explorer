## 확정된 결정

- HUD는 그림 위에 띄우고, 활동은 `hudInsets()`가 잰 바 사이 영역에만 배치한다. 새 HUD 요소가 활동을 가리면 이 함수에 반영한다.
- 9분할 카드는 직접 만든다. 게임이 Canvas 렌더러라 Phaser NineSlice(WebGL 전용)를 못 쓴다.
- 높이 520px 이하 휴대폰 가로는 스크롤을 허용한다. 화면을 더 줄이면 캔버스 글자가 겹쳐서다.
- 3D는 확대창·보상창·엔딩에서만 지연 로드하고, 2D 대체 화면을 유지한다.
- 운영 배포(Cloudflare)는 사용자 별도 승인 전까지 하지 않는다. 운영은 아직 0.7.0이다.
- 교육 판단이 필요한 변경(A4·B2·D1)은 사용자와 함께 정한다.

### A. 햇살 온실 (1순위)
- **A1 센서 직접 꽂기**: 물기 센서는 흙에, 빛 센서는 잎 높이에 끌어다 대면 바늘이 움직이며 '부족/충분'. 버튼은 보조로 유지.
