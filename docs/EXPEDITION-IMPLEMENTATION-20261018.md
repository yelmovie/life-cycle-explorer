# 0.5.0 탐험·의뢰 구현과 중단 복구

2026-10-18. 중단된 대화의 마지막 요청은 쉬운 목적, 직접 조작, 지훈의 참여, 문제 해결과 실용적인 보상이다. 당시 계획·이전 버전 사본·지도 WebP만 프로젝트에 적용돼 있었다. 생성 완료된 지훈 동작/도구 아틀라스는 원래 출력에서 D: 프로젝트로 복사하고 연결했다. 재생성 호출은 하지 않았다.

## 실제 흐름

| 구역 | 문제와 조작 | 결과·보상·다음 효용 |
|---|---|---|
| 나비의 숲 | 네 모습 관찰·그림, 시간 필름·비교 뒤 단서 네 장을 모습에 드래그. 다음 세대의 알을 구별 | 시간 손잡이 → 다음 씨앗 실험의 날짜를 회전으로 조작 |
| 씨앗 연구소 | 기존 공정한 A/B·시간·재실험 뒤, 물 없는 씨앗과 추운 씨앗을 각각 한 조건 비교로 해결. 6일 이후 두 결과를 기록 | 관찰 센서 → 다음 온실에서 물·빛을 대상에 놓아 조사 |
| 햇살 온실 | 물·빛 센서 둘로 원인을 확인하고 해당 돌봄 도구를 화분에 드래그. 시간이 지난 새잎을 확인. 두 원인을 각각 해결 | 계절 나침반 → 다음 정원에서 겨울·다음 봄의 개체 추적 |
| 사계절 정원 | 기존 독립 시간축·개체 표식·분류 뒤, 개·사과나무·새 장미의 자료를 관찰 근거와 연결 | 이야기 카메라 → 다음 스튜디오의 기록 선택기를 장면에서 열어 실제 자료로 구성 |
| 생명 시계탑 | 자기 이야기·고리·실제 관찰 약속 뒤, 세 도움 요청에 관찰/재실험/돌봄의 실제 기록 ID를 연결 | 다섯 구역 복원·개인 수행 인증·자기 기록 PNG |

오답은 이전 정답과 기록을 지우지 않는다. 씨앗의 두 조건을 함께 바꾸면 실행을 막고 이유를 알려 준다. 시작한 실험 조건은 잠근다. 센서 확인 없이 돌보거나 잘못된 도구를 쓰면 다음 행동의 단서를 준다. 성장·회복은 기다리는 타이머가 아니라 학생의 시간 장치 조작으로 비교한다. 모형은 실제 사육·재배를 보조한다.

## 파일과 상태

- `expedition.js`: 의뢰 자료, 명령 검증, 수행 조건, 실물 기록 참조, 안전한 복원.
- `expedition-scenes.js`: 드래그 대상, 회전 손잡이, 단서·화분·근거·기록 장면.
- `game-app.js`: 도움 요청, 학습/의뢰 전환, 접힌 버튼 대안, 도구 가방, 인증. 실험의 조건·예상은 선택기 두 개로 줄이고 배치 버튼은 접었다.
- `game-scenes.js`: 새 지도 입구와 연결 길, 터치/방향키 이동, 구간마다 위치 저장, 지훈의 행동 그림, 다음 활동의 도구. 기록 이미지 텍스처는 화면 전환 시 정리한다.
- `game-model.js`: 기존 저장키와 version 3 유지, 별도 `expedition.version: 1`. 예전 완료/책/그림 보존, 새 의뢰 수행을 지어내지 않는다. 새 구역 완료에는 기본 탐구와 의뢰가 모두 필요하다.
- `assets/expedition/generation.json`: 이전 내장 image_gen 호출의 실제 프롬프트·ID·원본 대응. `manifest.json`: 지도 및 아틀라스에서 준비한 실행 사본. 원본은 `source/`에 보존했다.

모달을 닫을 때 전체 장면을 재구성하던 동작이 빠른 다음 입력의 이동을 취소하는 문제를 실제 브라우저에서 발견했다. 닫기에서는 입력·시간만 재개하도록 수정했다. 지도 레이아웃의 명시적 grid 행도 확인했다.

## 검증

`npm run check`, `npm test`(82/82), `npm run build` 통과. 배포 패키지는 15개 실행 파일과 68개 참조 이미지이며 원본·과거 버전·QA 자료는 제외한다.

Chrome의 별도 QA 세션에서 새 의뢰 다섯 개를 실제 드래그·회전·버튼으로 완료했다. 잘못된 단서/조건/돌봄/장미/증거, 중간 새로고침, 보상, 인증, 도구 가방, PNG 미리보기, 초기화를 확인했다. 기존 탐구 증거는 fixture로 제공했으며 새 이용자가 빈 상태에서 열 탐구 전체를 완주했다고 주장하지 않는다.

1024×768에서는 씨앗의 흙·씨앗 배치, 조건·예상 선택, 시간별 사진, 재실험, 온실 센서 배치, 돌봄·시간·사진·문장부터 새 의뢰까지 따로 조작했다. 새 의뢰 화면은 1280×800와 1024×768, 지도는 추가로 1920×1080와 915×412에서 확인했다. 검증 결과와 화면은 `docs/reviews/expedition-20261018/`에 있다.

PNG 표본은 1800×1160(3장)이며 실제 선택한 기록과 설명을 포함한다. 기록 수에 따라 높이가 달라진다. 콘솔 오류/경고와 HTTP 오류는 0건이었다. 실물 터치·학생 이해도/흥미·학교망·외부 배포 검증은 남아 있다.

GitHub 저장소는 확인 당시 커밋이 없었다. 기존 D: 폴더에 main 저장소를 초기화하고 origin을 연결했다. 결과는 로컬 커밋으로 보관한다. 공개 서비스 배포는 수행하지 않는다.
