# 0.6.0 기능향상기 — 문제를 풀기보다 증거를 만드는 탐험

이전 0.5.0의 관찰·실험과 추가 의뢰가 탭·메뉴에 흩어져 있었다. 이번에는 학생이 한 화면에서 문제를 보고, 도구로 조사하고, 조건을 바꾸고, 결과를 기록하는 다섯 탐사로 바꿨다. 대기 시간을 늘리거나 같은 클릭을 반복해 분량을 채우지 않았다.

## 학습과 활동 연결

| 성취기준 | 남는 수행 | 수업에서 이어 할 일 |
|---|---|---|
| [4과04-01] 동물의 한살이를 직접 관찰하고, 관찰한 내용을 글과 그림으로 표현할 수 있다. | 네 모습의 두 부분 확대 관찰, 실제 선 그림·자기 문장, 자라는 필름과 다음 세대 | 실제 생물을 지속적으로 관찰하고 글·그림으로 기록 |
| [4과04-02] 식물이 자라는 데 필요한 조건을 찾는 실험을 설계하여 수행할 수 있다. | 같은 흙·씨앗 수, 한 조건 변경, 예상, 시간별 사진, 두 결과의 조건 비교, 물·빛 센서와 돌봄 | 실제 재배에서 조건 통제·관찰 기간·생물의 안전 함께 확인 |

발아에는 물·알맞은 온도, 자라는 식물에는 물·빛을 다루며 서로 혼동하지 않는다. 키만 크다고 건강하다고 판정하지 않는다. 부모가 알로 돌아가는 대신 다음 세대가 시작된다. 겨울을 지난 사과나무 A-01은 같은 개체이고, 봉선화 B-01의 씨앗에서 난 B-02는 새 개체다. 나비와 개의 실제 성장 기간을 같은 날짜로 맞추지 않는다.

## 문제·조작·보상·재탐사 매트릭스

| 구역 | 긴장과 판단 | 직접 조작 | 즉시 돌아오는 결과·다음 보상 | 다시 할 이유와 한계 |
|---|---|---|---|---|
| 나비의 숲 | 숨은 부분과 흩어진 성장 순서, 부모와 다음 세대 구분 | 실제 2배 렌즈, 그림, 필름 이동·재생, 새 알 옮기기 | 발견 표시와 자기 기록, 씨앗 날짜를 움직일 시간 손잡이 | 다른 모습을 골라 새 특징 그리기. 표본은 고정 |
| 씨앗 연구소 | 예상과 실제 결과의 차이, 다른 조건을 건드리면 비교 불가 | 재료 배치, B 조건 변경, 시간 회전·사진·단면, 근거 연결 | 싹과 뿌리의 차이·내 예상 비교, 온실 관찰 센서 | 다른 예상을 남겨 결과와 비교. 물·온도 사례는 고정 |
| 햇살 온실 | 비슷한 겉모습이라도 원인이 다름, 잘못된 도움에 재안내 | 두 센서 이동, 관찰핀, 전후 사진, 돌봄 도구와 시간 | 센서값과 새잎 변화, 계절 나침반 | 겉모습·측정·돌봄 순서를 다시 설명. 두 화분은 고정 |
| 사계절 정원 | 각자의 시간과 개체 표식이 이어지는지 추적 | 독립 시간, 사진, 이름표, 사계절 회전, 새 사례 연결 | 사라진 식물의 씨앗과 남은 줄기 확인, 이야기 카메라 | 다른 계절 순서로 증거 수집. 핵심 결론은 같음 |
| 생명 시계탑 | 세 도움 요청에 맞는 실제 증거 선별 | 기록 선택·순서 편집·자기 설명·근거 연결·생활 관찰 계획 | 숲 복원, 내 그림·조건·문장을 담은 이야기와 수행 기록증 | 새 주제와 순서로 이야기 다시 만들기. 자유 제작이 중심이고 경쟁·확률 요소 없음 |

그림과 캐릭터를 걷어내도 관찰→판단→조건 변경→결과 비교와 자기 자료 제작이 남는다. 반사신경 타이머·실패 시 진도 삭제는 없다. 사례가 고정되어 있다는 점과 학생 대상 재미·학습효과의 실험이 없다는 점은 한계로 남긴다.

## 첫 3분에 보이는 목적

첫 화면의 “멈춰 버린 숲의 시간을 이어 줘”, “네가 찾은 증거로 숲을 깨워 봐”, “내 기록책과 탐험 기록증” → 지훈의 멈춘 시계 이야기 → 지도 첫 장소의 문제 → 나비의 네 모습을 관찰하는 도구로 이어진다. 각 장소 칩에 받을 도구가 예고되고, 보상 화면에는 다음 장소에서 어떻게 쓰는지 나온다. 지도 완료 표시·잠긴 길의 안내·설정의 도구 가방에서 진행을 확인한다. 학생이 이 목적을 실제로 이해하는지는 수업 관찰이 필요하다.

## 화면과 캐릭터

전체 화면 배경 위 네 개의 도구 아이콘, 한 질문, 필요한 도구와 다음 버튼으로 정리했다. 지도 좌표를 실제 카메라 좌표로 변환하고, DOM 버튼 입력이 길 터치로 중복 처리되던 문제를 수정했다. 지훈의 돋보기·시간·돌봄·기록 포즈를 구역마다 바꾸고 말풍선은 직접 눌러 연다. 보상은 같은 그림을 다음 활동 도구로 사용한다.

새 관찰 숲 배경 1장을 생성하고 438KB WebP로 적용했다. 지도·지훈·도구는 기존 프로젝트 화풍을 유지했다. 우당탕 프로젝트에서 쓰는 Jua 로컬 폰트를 재사용하고 원래 OFL 고지를 포함했다. CSS는 화면 틀·가독성과 입력만 담당하고 세계·생물·도구는 그림이 담당한다. 작은 화면에서도 캔버스 본문은 실제 약 20px 이상을 유지한다.

## 저장과 내보내기

새 field 모델은 이전 inquiry·expedition 저장과 독립이다. 새 증거가 없으면 완료·보상이 생기지 않는다. 완료 시 최초 증거 snapshot을 보관하여 재탐사와 새 이야기 제작 중에도 기존 기록이 남는다. 기록 그림은 실제 관찰 부분·그림·문장, 고정 실험 조건·찍은 날짜·예상, 돌봄 전후, 개체 표식에서 만든다. 네 모습의 그림·글은 공통 관찰 노트라고 명시한다.

설정에는 소리 두 스위치·음량, 이야기 다시 보기, 완료 후 엔딩·기록증, 가이드·성취기준·미리보기·출처·초기화 확인을 넣었다. 미리보기는 잠금만 열고 실제 증거를 만들어 주지 않으며 학생 저장에 쓰지 않는다. 저장 실패에도 활동을 계속하고 진행 JSON을 보관할 수 있다. JSON 복원 UI는 없다.

## 검증과 남은 범위

- 자동 검사 97개와 활성 파일 25개 문법 검사 통과. 이전 자료 복원과 새 모델의 증거·완료·오답·재탐사 검증 포함.
- 빈 상태부터 다섯 구역을 실제 브라우저 조작으로 완주. 그림·글·실험·오답·돌봄·계절·실제 증거 연결·두 PNG·전체 저장 복원 확인.
- 6개 해상도의 42개 화면, 설정 스크롤·초기화 취소 초점, 미리보기 원본 복귀, 재탐사 후 새로고침, 저장 용량 오류와 JSON 보관 확인.
- dist에서 실제 터치 이벤트로 도구 선택·대상 누르기, 씨앗 드래그, 이미 기록이 놓인 이야기판에 추가 드래그 확인.
- 학교 실기기·전자칠판 뒤쪽 가시성·30명 학교망·실제 스피커 청취·오프라인 완주는 미검증. 영상·PWA는 추가하지 않았다.

세부 근거와 점수는 최종점검 문서에 기록한다. Git 원격 push와 공개 배포는 이번 범위에 포함하지 않았다.
