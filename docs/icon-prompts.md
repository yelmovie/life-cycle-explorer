# 공통 아이콘 제작 규칙

2026-10-21. 이번 화면의 공통 아이콘은 이모지와 별도 생성 이미지를 쓰지 않고 직접 작성한 SVG로 통일해요.

| 용도 | SVG 의미 | 표시 규칙 |
|---|---|---|
| 홈 | 지붕과 출입문이 보이는 집 | 왼쪽 위, 접근성 이름 `처음으로` |
| 이전 | 왼쪽 방향 화살표 | 홈 옆, 접근성 이름 `이전 화면` |
| 소리 | 스피커와 음파, 음소거는 사선 | 오른쪽 위, 현재 음소거 상태를 이름에 포함 |
| 설정 | 톱니와 가운데 원 | 소리 옆, 접근성 이름 `설정 열기` |
| 카메라 | 카메라 몸통과 둥근 렌즈 | 관찰 활동 안에서만, 접근성 이름을 실제 동작으로 지정 |

모두 `viewBox="0 0 24 24"`, 2~2.25px 선, 둥근 끝, `currentColor`를 사용해요. 아이콘 자체는 `aria-hidden="true"`, 버튼에는 한글 접근성 이름을 넣고 터치 영역은 최소 44px로 유지해요. 공통 네 아이콘 밖의 가방·별·보상은 화면 상단에 더하지 않고 활동 속 오브젝트나 설정 안에서 설명해요.

이미지 생성 프롬프트는 필요 없어요. 실제 관찰장 그림의 사용 프롬프트는 `assets/field/prompt.txt`에 보관해요.
