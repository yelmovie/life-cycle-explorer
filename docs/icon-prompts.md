# 공통 아이콘 제작 규칙

2026-10-24 재점검. 공통 아이콘은 기존 `ui-icons.js`의 SVG를 유지한다. 활성 JS/CSS/HTML에서 U+1F300~U+1FAFF 그림 이모지 검색 결과는 0건이다. 상태 체크·숫자 등의 문자 표시는 아이콘 교체 대상으로 보지 않는다.

| 위치(파일:줄) | 현재 이모지 | 용도 | 생성 프롬프트 / 조치 | 규격 |
|---|---|---|---|---|
| `ui-icons.js:2` | 없음 | 홈 | 기존 집 SVG 유지 · 이미지 생성 불필요 | 24×24 viewBox |
| `ui-icons.js:3` | 없음 | 이전 | 기존 화살표 SVG 유지 · 이미지 생성 불필요 | 24×24 viewBox |
| `ui-icons.js:4` | 없음 | 소리 | 기존 스피커 SVG 유지 · 이미지 생성 불필요 | 24×24 viewBox |
| `ui-icons.js:6` | 없음 | 설정 | 기존 톱니 SVG 유지 · 이미지 생성 불필요 | 24×24 viewBox |
| `ui-icons.js:7` | 없음 | 관찰 사진 | 기존 카메라 SVG 유지 · 이미지 생성 불필요 | 24×24 viewBox |

| 용도 | SVG 의미 | 표시 규칙 |
|---|---|---|
| 홈 | 지붕과 출입문이 보이는 집 | 왼쪽 위, 접근성 이름 `처음으로` |
| 이전 | 왼쪽 방향 화살표 | 홈 옆, 접근성 이름 `이전 화면` |
| 소리 | 스피커와 음파, 음소거는 사선 | 오른쪽 위, 현재 음소거 상태를 이름에 포함 |
| 설정 | 톱니와 가운데 원 | 소리 옆, 접근성 이름 `설정 열기` |
| 카메라 | 카메라 몸통과 둥근 렌즈 | 관찰 활동 안에서만, 접근성 이름을 실제 동작으로 지정 |

모두 `viewBox="0 0 24 24"`, 2~2.25px 선, 둥근 끝, `currentColor`를 사용해요. 아이콘 자체는 `aria-hidden="true"`, 버튼에는 한글 접근성 이름을 넣고 터치 영역은 최소 44px로 유지해요. 공통 네 아이콘 밖의 가방·별·보상은 화면 상단에 더하지 않고 활동 속 오브젝트나 설정 안에서 설명해요.

이미지 생성 프롬프트는 필요 없어요. 실제 관찰장 그림의 사용 프롬프트는 `assets/field/prompt.txt`에 보관해요.
