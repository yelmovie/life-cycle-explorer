# PRD — 생명 시계 연구실 MVP

버전 0.1 · 2026-09-23 · 초기 구현의 역사 자료

> 2026-10-18 현재 제품은 Phaser 2D 지도·탐구 게임 0.4.0이다. 현재 요구사항은 [Phaser 고도화 계획](PHASER-PLAN-20261018.md), 구현 범위는 [변경 기록](PHASER-IMPLEMENTATION-20261018.md)을 따른다. 아래의 이전 화면·엔진 설명은 현재 구현 기준이 아니다.

## 제품과 사용자

초등 3학년 학생이 생물의 변화를 관찰하고, 실험 조건을 통제하고, 서로 다른 한살이를 비교한 다음 자기 기록을 소개 자료로 만드는 가로형 웹앱. 태블릿과 전자칠판에서 사용한다. 실제 사육·관찰을 대체하지 않는다.

## 확정 방향

- 5장 / 학습 화면 10개. 별도로 메인과 자연 선택 맵을 둬 총 12개 화면.
- 메인 다음 자연 선택 맵만 위에서 비스듬히 내려다보는 2.5D 픽셀아트 표현.
- 학습 화면과 엔딩은 2D 배경 + 분리된 조작 대상과 텍스트 UI.
- 학생 연구원 지훈, 잎 정령 기록관 잎새만 안내 캐릭터로 사용.
- 제공된 글자 없는 배경 10장을 장별로 재사용. 배경 1개에 장면 1개.
- 이전 PRD의 Three.js 및 3D 장면 요구는 현재 지시로 대체한다.
- 공유 대화 원문은 접근 실패. 로컬 기존 PRD, 제공 이미지, 사용자가 붙여 준 발췌와 명시적 수정 지시가 설계 근거다.

## 이야기

멈춘 생명 시계를 되살리기 위해 다섯 연구 구역의 기록을 복구한다. 관찰·발아·성장·다양성·기록의 링을 모으고, 본인이 만든 소개 자료와 함께 시계를 재가동한다.

## 장별 행동과 완료 기준

| 화면 | 행동 | 완료 기준 |
|---|---|---|
| 01 생명 스캔 | 배추흰나비 표본 렌즈 관찰, 확대, 핀, 메모 | 서로 다른 표본의 핀 3개 이상 + 특징 메모 |
| 02 시간 기록 | 관찰 회차 두 개를 선택하고 변화 비교 | 서로 다른 회차 + 변화 근거 문장 |
| 03 실험 설계 | 물 또는 온도 질문, A/B 조건 선택 | 질문에 해당하는 한 조건만 다름 |
| 04 시간 가속 | 0~7일 레버, 흙 속 보기, 시점 저장, 결론 | 시점 2개 이상(6일 이후 포함) + 모형 결과에 맞는 화분 선택 |
| 05 온실 복구 | 빛·수분 센서 설치, 싹튼 식물 조건 선택 | 센서 2개 + 질문에 해당하는 한 조건만 다름 |
| 06 성장 분석 | 조건과 그래프를 보고 주장/조건/근거 연결 | 세 항목 모두 저장한 실험과 일치 |
| 07 생명 조사 | 동물끼리, 식물끼리 같은 기준으로 비교 | 각 종류의 생물 쌍에 서로 다른 기준의 기록 2개 |
| 08 패턴 분석 | 6개 생물 유형 분류와 기록 근거 연결, 장미에 적용 | 분류·근거·전이 사례 모두 일치 |
| 09 기록 제작 | 수집 자료 3~6개로 장면 구성, 재배열, 설명/요약 | 제목 + 장면 3개 이상 + 특징 설명 2개 + 요약 |
| 10 시계 복구 | 대표 기록 확인, 링 5개 결합, 결과 카드 저장 | 앞선 미션 9개 완료 + 링 5개 확인 |

문장 길이 검사는 빈 입력 방지를 위한 최소 기준일 뿐, 과학적으로 올바른 서술임을 자동 판정하지 않는다. 교사가 연구 노트와 결과물을 보고 피드백한다.

## 진행과 보상

앞선 미션을 완료해야 다음 미션에 진입한다. 각 장의 두 번째 미션을 마치면 자연 맵으로 돌아가며 다음 구역이 열린다. 완료된 장은 다시 방문할 수 있다. 완료된 실험의 조건은 고정하여 후속 기록과 일치시킨다. 새 조건으로 전체 연구를 다시 시작하려면 설정의 초기화를 사용한다. 초기화 전 명시적인 확인과 결과 저장 안내를 제공한다.

## 데이터와 결과물

관찰핀, 메모, A/B 조건, 관찰 시점, 성장 해석, 비교 기록, 작품 장면과 설명, 완료 상태를 자동 저장한다. 결과 PNG에는 사용자가 작성한 설명·요약과 원래 수집한 근거를 함께 담는다. 이름/학번/로그인 입력은 없다.

## MVP 제외

3D, 캐릭터 자유 이동, 전투, 음성 녹음, 카메라 촬영, 사진 업로드, 자유 그리기, 영상 출력, 서버 공유, 정밀 생장 예측, PWA 오프라인 설치, 정식 학습 평가/교사용 관리 화면. 현재 표본과 생장도는 간략화한 SVG 학습 도해다.

## 확인 기준

초기 상태에서 엔딩까지 이어지는 실제 조작 경로, 불공정한 조건 차단, 새로고침 복원, 기록 재사용과 PNG 저장, 1280×800 및 1024×768에서 조작 대상의 가로 잘림 여부를 검증한다. 기타 크기와 실제 터치 장치는 검증 범위를 명시한다.

## 공통 상단 메뉴 추가

모든 화면의 왼쪽 상단에 홈/이전 페이지 아이콘, 오른쪽 상단에 효과음/톱니바퀴 설정 아이콘을 제공한다. 이전 페이지는 앱 안에서 실제로 방문한 화면을 거슬러 이동하며, 기록이 없으면 직전 미션/지도/홈으로 돌아간다. 효과음은 짧은 클릭 소리이며 사용자 조작 후 Web Audio로 재생한다.

설정의 `관리자 전체 해금`은 하나의 스위치로 모든 구역과 10개 미션을 함께 연다. 미완료 상태에서도 다음 페이지를 확인할 수 있지만 미션을 자동 완료하거나 관찰 기록을 생성하지 않는다. 끄면 원래 진행 기록에 따른 잠금이 복원되며, 현재 화면이 다시 잠기면 지도로 돌아간다. 공개 데모 검토용 기능이며 인증/권한 보안 기능은 아니다. 두 설정은 브라우저에 저장된다.
