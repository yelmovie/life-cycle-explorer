# 생명 시계 연구실 · Phaser 탐구 게임

버전 0.5.0 · 2026-10-18. 가로 태블릿을 위한 2D 지도 탐험 + 5구역/10개 탐구 활동 + 구역별 문제 해결 의뢰. 지훈과 잎새가 관찰·실험·돌봄·비교·이야기 기록으로 생명 시계를 복원한다.

## 실행과 빌드

Node.js 20 이상. Phaser 3.90.0은 `vendor/`에 포함되어 있으며 외부 패키지 설치와 CDN 연결이 필요 없다.

```sh
npm start
npm run check
npm test
npm run build
npm run preview
```

개발/미리보기 서버는 [127.0.0.1:4186](http://127.0.0.1:4186)에서 실행한다. 동시에 실행할 때는 PowerShell에서 `$env:PORT='4196'`처럼 별도 포트를 지정한다. `npm run preview`는 `dist/`를 제공한다. 외부 정적 호스팅에는 **dist 내용만** 업로드한다. `file://` 직접 실행은 지원하지 않는다. 외부 공개 배포는 수행하지 않았다.

## 현재 활동

- 새로 생성한 숲 마을에서 길을 터치하거나 방향키로 이동한다. 각 구역은 도움 요청 → 탐구 2개 → 새 문제 해결 → 다음 구역에서 쓰는 도구로 이어진다.
- 나비 관찰 단서 4개, 물·온도 조건의 씨앗 2사례, 센서로 진단하고 돌보는 화분 2사례, 개·사과나무·장미의 근거 연결, 자기 증거로 해결하는 마지막 의뢰가 추가됐다.
- 시간 손잡이·관찰 센서·계절 나침반·이야기 카메라를 실제 다음 활동에서 사용한다. 도구 가방에서 얻은 것과 다음 효용을 확인한다. 오답으로 진도와 기록을 잃지 않는다.
- 길을 따라 이동하는 Phaser 지도, 5구역 해금과 숲 복원.
- 실제 2배 관찰 렌즈·위치 핀·그림, 필름 순서 편집·재생·전후 비교.
- 화분에 도구 배치, 한 조건만 다른 A/B 실험, 시간 레버·흙 속 단면·시점 사진·재실험.
- 물/빛 센서, 원인에 맞는 돌봄, 시간이 지난 뒤의 변화 기록.
- 동물별 독립 시간축, 겨울과 다음 봄의 개체 표식, 근거 분류와 새 장미 사례.
- 자기 그림·사진·조건·비교 기록을 골라 설명과 순서를 편집하고 재생·PNG 출력.
- 실제 기록으로 5개 고리 연결, 직접 관찰할 약속과 수행 기반 인증.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html`, `game.css` | 진입점, 가로 화면 틀·DOM 조작부·모달 |
| `game-app.js` | 화면 흐름·입력·기록함·내보내기 |
| `game-scenes.js` | Phaser 지도·장면·드래그·렌즈·애니메이션·단계별 에셋 로딩 |
| `game-model.js` | 탐구 로직 연결·경로·저장·중복 증거 갱신 |
| `expedition.js`, `expedition-scenes.js` | 다섯 의뢰의 상태·검증·저장 복원, 드래그·시간 장치·실제 증거 연결 |
| `inquiry-core.js`, `adventure-core.js` | 검증된 탐구 상태·완료 조건·교육용 모형 |
| `game-records.js`, `adventure-export.js` | 실제 관찰 기록 이미지·PNG 출력 |
| `game-assets.js`, `game-metadata.js` | 실행 에셋 주소·명칭·보상 자료 |
| `assets/game/`, `assets/expedition/`, `vendor/` | 화면용 사본·생성 지도/캐릭터/도구·원본/프롬프트, 고정 버전 엔진·라이선스 |
| `tests/`, `scripts/build.mjs` | 상태 회귀 검사·필요한 실행 파일만 패키징 |

기존 `app.js`, `adventure.js`, `inquiry-ui.js`와 원본 에셋은 보존되어 있지만 현재 진입점과 배포 빌드에서 사용하지 않는다. 장면을 바꾸려면 `game-scenes.js`, 조작부는 `game-app.js`, 완료 조건은 `game-model.js`와 연결된 core를 함께 확인한다. 콘텐츠 전체가 JSON으로 분리된 구조는 아니다.

## 저장과 수업 범위

진도·그림·문장은 현재 브라우저의 `life-clock-lab.phaser.4`에 저장한다. 기존 v3/v2 탐구 기록은 최초 실행 때 복사해서 읽으며 이전 저장키를 덮어쓰지 않는다. 포트·도메인·브라우저가 달라지면 저장 공간도 달라진다. 브라우저 데이터 삭제 시 기록을 잃을 수 있으므로 완성 자료를 PNG로 보관한다. 서버 계정·학생 명단 수집·기록 전송은 없다.

0.4.0의 완료·그림·책은 보존한다. 새 의뢰 수행과 도구 획득은 별도로 기록하므로 예전 완료로 자동 생성되지 않는다. 이전 이용자는 지도에서 열린 구역을 다시 찾아 의뢰를 해결할 수 있다. 기본 탐구와 새 의뢰를 모두 마쳐야 해당 구역의 새로운 복원·보상을 받는다.

자동 검사는 기존 73개와 신규 의뢰 9개로 총 82개다. 선택적인 브라우저 검증 스크립트는 `scripts/verify-expedition.mjs`, `scripts/verify-inquiry-controls.mjs`이다. 이미 설치된 Playwright를 `PLAYWRIGHT_MODULE`로 지정하고 Chrome과 로컬 서버가 있는 환경에서 실행한다. 별도 브라우저 세션의 QA 자료만 사용하며 사용자 저장을 초기화하지 않는다.

이 앱은 실제 사육·재배를 보조하는 교육용 모형이다. 자유 서술의 과학적 타당성은 자동 채점하지 않는다. 실제 학교 태블릿·학교망·접속이 끊긴 상태에서의 완주는 별도 검증이 필요하다. 화면 검증의 우선 크기는 1280×800, 1024×768이다. 작은 휴대전화와 전자칠판 전용 확대 모드는 현재 목표 범위가 아니다.

도입·엔딩 영상은 아직 포함하지 않았다. [영상 제작 캔버스](https://chatgpt.com/space/page_5ae3aacdd760819188b087223d50cc5c)에 캐릭터 일관성·샷·시간·카메라·마지막 구도를 정리했다. 영상 없이도 탐구와 최종 복원이 완료된다.
